; NeptuneBASIC command descriptions: the source of docs/COMMANDS.md and of
; the editor hover help. "# Category" starts a group; each command is one
; "Name: description" line; "(ext)" marks commands added to the classic command set.
; After adding a command, describe it here and run python tools/gen_reference.py.

# Program and system
RuntimeError: Stops the program with a runtime error showing message.
CommandLine: Returns the arguments passed to the program after the source or program name, joined by spaces.
GetEnv: Returns the value of the environment variable name, or an empty string if it is not set.
SetEnv: Sets the environment variable name to value for this program and any programs it starts.
SystemProperty: Returns a system property as a string: "appdir", "tempdir", "currentdir", "homedir", "windowsdir" and "systemdir" give folders ending in a path separator, "os" the operating system name and "cpucount" the number of CPU cores. Unknown properties return an empty string.
ExecFile: Opens file with the program the operating system associates with it (a document, web address or program); does not wait for it to finish.

# Console input and output
Print: Writes value (any type, default an empty string) to the console followed by a new line.
Write: Writes value (any type) to the console without a new line.
Input: Shows prompt on the console, waits for the user to type a line and returns it as a string without the line ending.
DebugLog: Writes message to the debug log (standard error), followed by a new line.

# Maths
Sqr: Returns the square root of value.
Sin: Returns the sine of an angle in degrees.
Cos: Returns the cosine of an angle in degrees.
Tan: Returns the tangent of an angle in degrees.
ASin: Returns the arc sine of value, in degrees.
ACos: Returns the arc cosine of value, in degrees.
ATan: Returns the arc tangent of value, in degrees.
ATan2: Returns the angle in degrees of the point (x, y) from the origin, from -180 to 180; note the y parameter comes first.
Exp: Returns e raised to the power value.
Log: Returns the natural logarithm of value.
Log10: Returns the base-10 logarithm of value.
Floor: Returns value rounded down to the nearest whole number, as a float.
Ceil: Returns value rounded up to the nearest whole number, as a float.
Min: (ext) Returns the smaller of a and b.
Max: (ext) Returns the larger of a and b.
Clamp: (ext) Returns value limited to the range low to high.
Lerp: (ext) Returns the value a fraction t of the way from a to b (t = 0 gives a, t = 1 gives b).
Ease: (ext) Returns how far along an easing curve is at time t (0 start, 1 end): EASE_LINEAR, EASE_IN (starts slow), EASE_OUT (ends slow), EASE_IN_OUT (the default), EASE_IN_CUBIC, EASE_OUT_CUBIC, EASE_IN_OUT_CUBIC, EASE_IN_SINE, EASE_OUT_SINE, EASE_IN_OUT_SINE, EASE_IN_BACK, EASE_OUT_BACK, EASE_IN_OUT_BACK (overshoot a little), EASE_IN_ELASTIC, EASE_OUT_ELASTIC (wobble), EASE_IN_BOUNCE, EASE_OUT_BOUNCE. Use it to move anything smoothly.
EaseBetween: (ext) Returns the value between from and to at time t (0-1) along easing curve ease, for smooth movement of menus, counters and anything else.

# Random numbers
SeedRnd: Seeds the random number generator with seed so the same sequence of numbers is produced each run; MilliSecs() is a common seed.
Rnd: Returns a random float between from and to; with only one parameter it returns a float between 0 and from.
Rand: Returns a random integer between from and to inclusive; with only one parameter it returns an integer between 1 and from.
RndSeed: Returns the seed last set with SeedRnd.

# Strings
Left: Returns the first count characters of string.
Right: Returns the last count characters of string.
Mid: Returns count characters of string starting at character offset (1 is the first character); with count left at -1 it returns the rest of the string.
Len: Returns the number of characters in string.
Upper: Returns string in upper case.
Lower: Returns string in lower case.
Trim: Returns string with spaces and other white space removed from both ends.
LSet: Returns string padded with spaces on the right, or cut, to exactly size characters.
RSet: Returns string padded with spaces on the left, or cut from the left, to exactly size characters.
Instr: Returns the position of find in string, searching from character from (default 1), or 0 if it is not found.
Replace: Returns string with every occurrence of from replaced by to.
String: Returns string repeated count times.
Chr: Returns the one-character string for the character code code.
Asc: Returns the character code of the first character of string, or -1 for an empty string.
Hex: Returns value as an 8-digit hexadecimal string.
Bin: Returns value as a 32-digit binary string.
TypeOf: (ext) Returns the name of the type of value as a string, such as "Int", "Float" or "String".
FormatFloat: (ext) Returns value as a string with decimals digits after the decimal point (0 to 9).

# Files and folders
FileType: Returns 1 if path is a file, 2 if it is a folder, or 0 if it does not exist.
FileSize: Returns the size of the file at path in bytes, or 0 if it does not exist.
DeleteFile: Deletes the file at path.
CopyFile: Copies the file from to the path to.
CreateDir: Creates the folder path.
DeleteDir: Deletes the folder path; it must be empty.
CurrentDir: Returns the current folder, ending in a path separator.
ChangeDir: Makes path the current folder.
ReadDir: Opens the folder dirname for listing and returns a handle, or 0 if it cannot be opened.
NextFile: Returns the next name in the folder listing dir ("." and ".." come first), or an empty string when there are no more; use FileType to tell files from folders.
CloseDir: Closes the folder listing dir.

# Settings and save data
UserFolder: (ext) Returns the folder (made if needed) where a game should keep its settings and saves: the user's application data folder with a folder named app in it (default "NeptuneBASIC"), ending in a path separator. It is writable on every system, unlike the game's own folder.
SetSetting: (ext) Stores value as the setting called name (in memory; SaveSettings writes them all to a file). Names are not case sensitive and may use dots to group them, like "audio.music" or "slot1.level".
GetSetting: (ext) Returns the setting called name, or default if there is none.
GetSettingInt: (ext) Returns the setting called name as a whole number, or default if there is none or it is not a number.
GetSettingFloat: (ext) Returns the setting called name as a number, or default if there is none or it is not a number.
SettingExists: (ext) Returns 1 if there is a setting called name.
DeleteSetting: (ext) Removes the setting called name.
ClearSettings: (ext) Removes every setting from memory.
SaveSettings: (ext) Writes every setting to file as name = value lines, a text file people can read and edit.
LoadSettings: (ext) Reads settings from file (adding to or replacing those in memory) and returns 1, or 0 if the file does not exist.

# Streams
ReadFile: Opens the file at path for reading and returns a stream handle, or 0 if it cannot be opened.
WriteFile: Creates (or empties) the file at path for writing and returns a stream handle, or 0 on failure.
OpenFile: Opens an existing file at path for reading and writing and returns a stream handle, or 0 on failure.
CloseFile: Closes the file stream.
Eof: Returns true once stream has no more data to read (for a TCP stream, when the connection has closed).
ReadLine: Reads a line of text from stream and returns it without the line ending.
WriteLine: Writes text to stream followed by a line ending.
ReadByte: Reads one byte (0-255) from stream and returns it.
ReadShort: Reads a 2-byte unsigned integer (0-65535) from stream and returns it.
ReadInt: Reads a 4-byte integer from stream and returns it.
ReadFloat: Reads a 4-byte float from stream and returns it.
ReadString: Reads a string stored as a 4-byte length followed by its characters (as written by WriteString) from stream.
WriteByte: Writes value to stream as one byte.
WriteShort: Writes value to stream as a 2-byte integer.
WriteInt: Writes value to stream as a 4-byte integer.
WriteFloat: Writes value to stream as a 4-byte float.
WriteString: Writes value to stream as a 4-byte length followed by its characters.
ReadAvail: Returns how many bytes can be read from stream without waiting: for a file, the bytes left before its end.
FilePos: Returns the current read/write position in the file stream, in bytes from the start.
SeekFile: Moves the read/write position of the file stream to pos bytes from the start and returns the new position.
CopyStream: Copies all remaining data from src_stream to dest_stream, buffer_size bytes at a time.

# Banks
CreateBank: Creates a bank (a block of memory) of size bytes, filled with zeros, and returns its handle.
FreeBank: Deletes bank.
BankSize: Returns the size of bank in bytes.
ResizeBank: Changes the size of bank to size bytes, keeping its contents; new bytes are zero.
CopyBank: Copies count bytes from src_bank at src_offset to dest_bank at dest_offset.
PeekByte: Returns the byte (0-255) at offset in bank.
PeekShort: Returns the 2-byte unsigned integer at offset in bank.
PeekInt: Returns the 4-byte integer at offset in bank.
PeekFloat: Returns the 4-byte float at offset in bank.
PokeByte: Writes value as one byte at offset in bank.
PokeShort: Writes value as a 2-byte integer at offset in bank.
PokeInt: Writes value as a 4-byte integer at offset in bank.
PokeFloat: Writes value as a 4-byte float at offset in bank.
ReadBytes: Reads up to count bytes from stream into bank starting at offset and returns the number of bytes read.
WriteBytes: Writes count bytes from bank starting at offset to stream and returns the number written.

# Time and timers
MilliSecs: Returns the number of milliseconds since the program started.
Delay: Pauses the program for millisecs milliseconds.
CurrentDate: Returns today's date as a string in the form "dd Mon yyyy".
CurrentTime: Returns the current time as a string in the form "hh:mm:ss".
CreateTimer: Creates a timer that ticks hertz times per second and returns its handle; use it with WaitTimer to run a program at a steady frame rate.
WaitTimer: Waits until timer next ticks and returns the number of ticks that have passed since the last call (at least 1).
FreeTimer: Deletes timer.

# Networking
OpenTCPStream: Connects to server (a host name or IP address) on port and returns a TCP stream handle, or 0 if the connection fails. Use the stream commands to send and receive.
CloseTCPStream: Closes the TCP stream.
CreateTCPServer: Starts a TCP server listening on port and returns its handle, or 0 on failure.
CloseTCPServer: Stops the TCP server.
AcceptTCPStream: Returns a stream for the next client that has connected to server, or 0 if none is waiting.
TCPStreamIP: Returns the integer IP address of the other end of the TCP stream; use DottedIP to show it.
TCPStreamPort: Returns the port of the other end of the TCP stream.
TCPTimeouts: Sets how long TCP reads wait for data (read_millis) and how long AcceptTCPStream waits for a client (accept_millis), in milliseconds.
CreateUDPStream: Opens a UDP stream on port (0 picks a free port) and returns its handle, or 0 on failure.
CloseUDPStream: Closes the UDP stream.
SendUDPMsg: Sends the data written to the UDP stream as one message to the integer IP address dest_ip and dest_port (0 uses the stream's own port).
RecvUDPMsg: Receives the next UDP message on stream so it can be read with the stream commands, and returns the sender's integer IP address, or 0 if there is none.
UDPStreamIP: Returns the local integer IP address of the UDP stream.
UDPStreamPort: Returns the local port of the UDP stream.
UDPMsgIP: Returns the integer IP address of the sender of the last message received on the UDP stream.
UDPMsgPort: Returns the port of the sender of the last message received on the UDP stream.
UDPTimeouts: Sets how long RecvUDPMsg waits for a message, in milliseconds (recv_millis).

# Multiplayer games
StartNetGame: Joins a game found on the local network, or hosts a new one if there is none. Returns 1 if it joined, 2 if it is hosting, or 0 on failure. Uses TCP, with no dialog.
HostNetGame: Hosts a multiplayer game called game_name that others can join, and returns 2 on success or 0 on failure.
JoinNetGame: Joins the game game_name at server_ip (an empty address searches the local network) and returns 1 on success or 0 on failure.
StopNetGame: Leaves or stops the current multiplayer game.
CreateNetPlayer: Creates a local player called name in the current game and returns its player id.
DeleteNetPlayer: Removes the local player from the game.
NetPlayerName: Returns the name of player.
NetPlayerLocal: Returns true if player was created on this computer.
SendNetMsg: Sends a message of type (1-99) with the text data from from_player to to_player (0 sends to all players). Returns true on success. reliable is accepted for compatibility: messages are always sent reliably.
RecvNetMsg: Fetches the next received message and returns true, or false if there is none; read it with NetMsgType, NetMsgFrom, NetMsgTo and NetMsgData.
NetMsgType: Returns the type of the last received message: 1-99 for player messages, 100 for a player joining, 101 for a player leaving and 200 when the session is lost.
NetMsgFrom: Returns the player id that sent the last received message (for type 100, the new player).
NetMsgTo: Returns the player id the last received message was sent to, or 0 if it was sent to everyone.
NetMsgData: Returns the text of the last received message.
DottedIP: Returns the integer IP address ip as a dotted string such as "192.168.0.1".
CountHostIPs: Looks up the IP addresses of host_name (an empty string for this computer) and returns how many were found.
HostIP: Returns address number index (from 1) found by the last CountHostIPs, as an integer IP address.

# Plugins and libraries
CallDLL: Calls the function proc_name in the shared library dll_name, passing the contents of in_bank and out_bank (0 for none); the function can write results into out_bank. Returns the function's integer result. The library stays loaded.

# Graphics and display
Graphics3D: Opens a window of width by height pixels for 3D and 2D graphics. mode 0 or 2 gives a window, 1 fullscreen, 3 a scaled window; depth is accepted for compatibility.
Graphics: Opens a window of width by height pixels for 2D graphics; mode 0 or 2 gives a window, 1 fullscreen, 3 a scaled window.
EndGraphics: Accepted for compatibility; does nothing.
AppTitle: Sets the window title to title. close_prompt is accepted for compatibility.
SetFullscreen: (ext) Switches between a window (enable = 0) and borderless fullscreen (enable = 1) at any time.
IsFullscreen: (ext) Returns true if the program is running fullscreen.
GfxMode3D: Returns true if graphics mode number mode exists and supports 3D.
GfxDriver3D: Returns true if graphics driver number driver supports 3D (only driver 1 exists).
WBuffer: Accepted for compatibility; depth precision is handled by the renderer.
ActiveTextures: Returns the number of different textures currently applied to entities.
GraphicsDepth: Returns the colour depth of the display in bits (always 32).
CountGfxModes: Returns the number of listed graphics modes (screen sizes).
CountGfxModes3D: Returns the number of listed 3D graphics modes.
GfxModeWidth: Returns the width in pixels of graphics mode number mode, or 0 if it does not exist.
GfxModeHeight: Returns the height in pixels of graphics mode number mode, or 0 if it does not exist.
GfxModeDepth: Returns the colour depth of graphics mode number mode (32), or 0 if it does not exist.
GfxModeExists: Returns true if width by height is one of the listed graphics modes; any size works in a window.
GfxMode3DExists: Returns true if width by height is one of the listed 3D graphics modes; any size works in a window.
CountGfxDrivers: Returns the number of graphics drivers (always 1).
GfxDriverName: Returns the name of graphics driver number driver, or an empty string if it does not exist.
SetGfxDriver: Accepted for compatibility; there is only one graphics driver.
Windowed3D: Returns true if 3D graphics can run in a window (always true).
GfxDriverCaps3D: Returns the 3D capability level of the graphics driver (always 110).
HWTexUnits: Returns the number of texture layers an entity can use at once.
HWMultiTex: Accepted for compatibility; does nothing.
Dither: Accepted for compatibility; does nothing.
TotalVidMem: Returns the total video memory in bytes; a fixed figure of 1 GB, since it cannot be read.
AvailVidMem: Returns the free video memory in bytes; a fixed figure of 1 GB, since it cannot be read.
VWait: Accepted for compatibility; Flip already waits for the display.
ScanLine: Returns the display scan line; always 0.
TrisRendered: Returns the number of triangles drawn by the last RenderWorld.
GraphicsWidth: Returns the width of the graphics window in pixels.
GraphicsHeight: Returns the height of the graphics window in pixels.
UpdateWorld: Updates animations, collisions and physics for one frame; elapsed_time scales how far animations advance (default 1).
RenderWorld: Renders the 3D world from every active camera, covering any 2D drawn before it. tween (0 to 1) blends each entity between its CaptureWorld position and its current one, for smooth fixed-rate loops; 1 draws the current positions.
Flip: Shows the finished frame on screen and ends the frame; vwait (default 1) waits for the vertical blank.
WireFrame: Draws all 3D geometry as wireframe when enable is 1, solid when 0.
ScreenFade: (ext) Fades a colour red, green, blue over the whole screen (3D and 2D) from its current opacity to alpha (0 clear, 1 solid) over seconds (default 0.5): fade to black between levels, flash white when hit. The colour stays at alpha until the next ScreenFade.
ScreenFading: (ext) Returns 1 while a ScreenFade is still changing.

# Gamma and quality
GraphicsQuality: (ext) Sets the renderer quality preset: level 0 low, 1 medium, 2 high, 3 ultra (QUALITY_LOW to QUALITY_ULTRA). Use a low level for old graphics cards.
GetGraphicsQuality: (ext) Returns the current quality level set with GraphicsQuality (0-3).
PostEffect: (ext) Turns a rendering effect on (enable = 1) or off (enable = 0): EFFECT_BLOOM, EFFECT_SSAO, EFFECT_FXAA, EFFECT_SHADOWS or EFFECT_LIGHT_SCATTER.
AntiAlias: Turns anti-aliasing (smoothing of jagged edges) on or off.
SetGamma: Sets the gamma ramp so that the colour levels src_red, src_green, src_blue (0-255) are shown as dest_red, dest_green, dest_blue. Call UpdateGamma to apply it.
UpdateGamma: Applies the gamma changes made with SetGamma; calibrate is accepted for compatibility.
GammaRed: Returns the output level the red level red (0-255) is mapped to by the gamma ramp.
GammaGreen: Returns the output level the green level green (0-255) is mapped to by the gamma ramp.
GammaBlue: Returns the output level the blue level blue (0-255) is mapped to by the gamma ramp.

# 2D drawing and text
Locate: Moves the text cursor used by Print and Write to x, y in pixels.
Viewport: Restricts 2D drawing to the rectangle at x, y with size width by height in pixels.
Text: Draws string at x, y in the current font and colour; center_x and center_y set to 1 centre it horizontally or vertically on that point.
Color: Sets the drawing colour for 2D commands, with red, green, blue from 0 to 255.
ColorRed: Returns the red part (0-255) of the current drawing colour.
ColorGreen: Returns the green part (0-255) of the current drawing colour.
ColorBlue: Returns the blue part (0-255) of the current drawing colour.
ClsColor: Sets the colour Cls clears to, with red, green, blue from 0 to 255.
Cls: Clears the current buffer to the ClsColor colour.
Origin: Sets the point x, y (pixels) that 2D drawing commands are measured from.
Rect: Draws a rectangle at x, y of width by height pixels, filled when solid is 1 (default) or as an outline when 0.
Oval: Draws an ellipse inside the box x, y, width, height (pixels), filled when solid is 1 (default) or as an outline when 0.
Line: Draws a line from x1, y1 to x2, y2 in pixels.
Plot: Draws a single pixel at x, y.

# Fonts
LoadFont: Loads a font fontname at height pixels, optionally bold, italic or underlined (1 = on). Returns the font handle, or 0 if it cannot be loaded.
SetFont: Makes font the font for Text and Print. Font 0 selects the built-in font (ext).
FreeFont: Frees font.
FontWidth: Returns the width of the widest character in the current font, in pixels.
FontHeight: Returns the height of the current font in pixels.
StringWidth: Returns the width of string in pixels in the current font.
StringHeight: Returns the height of string in pixels in the current font.

# 2D images
SaveImage: Saves frame of image to an image file; returns 1 on success, 0 on failure.
LoadImage: Loads an image file for 2D drawing. Returns the image handle, or 0 on failure.
LoadAnimImage: Loads an image strip of frames, each width by height pixels, starting at frame first and loading count frames. Returns the image handle, or 0 on failure.
FreeImage: Frees image.
DrawImageEx: (ext) Draws frame of image at x,y rotated by rotation degrees clockwise and scaled by scale_x and scale_y about its handle, with alpha from 0 (invisible) to 1 (solid).
DrawImage: Draws frame of image at x,y in pixels, with its mask colour transparent.
DrawBlock: Draws frame of image at x,y in pixels without transparency.
DrawImageRect: Draws the part of image starting at rect_x,rect_y and rect_width by rect_height pixels at x,y, with its mask colour transparent.
DrawBlockRect: Draws the part of image starting at rect_x,rect_y and rect_width by rect_height pixels at x,y, without transparency.
CreateImage: Creates a blank image width by height pixels with frames frames. Returns the image handle.
CopyImage: Returns a new image that is a copy of image.
GrabImage: Copies the area of the current buffer at x,y (minus the image handle) into frame of image.
RotateImage: Rotates image by angle degrees.
TFormImage: Transforms image by the 2x2 matrix a,b,c,d (for skewing, scaling and rotating).
TFormFilter: Turns smoothing on (1) or off (0) for RotateImage, ScaleImage, ResizeImage and TFormImage.
TileImage: Fills the whole current buffer with frame of image, offset by x,y, with its mask colour transparent.
TileBlock: Fills the whole current buffer with frame of image, offset by x,y, without transparency.
ImageRectCollide: Returns 1 if any solid (non-mask) pixel of frame of image drawn at x,y lies inside the rectangle at rect_x,rect_y of size rect_width by rect_height (pixel-accurate).
ImageWidth: Returns the width of image in pixels.
ImageHeight: Returns the height of image in pixels.
ImageXHandle: Returns the X offset of image's handle in pixels.
ImageYHandle: Returns the Y offset of image's handle in pixels.
ImageFrames: Returns the number of frames in image.
HandleImage: Sets the handle (drawing origin) of image to x,y pixels from its top-left corner.
MidHandle: Sets the handle of image to its centre.
AutoMidHandle: When enable is 1, images loaded or created afterwards get their handle at their centre; 0 puts it at the top-left corner.
MaskImage: Sets the colour of image (red, green, blue 0-255) that is drawn as transparent. The default is black.
ScaleImage: Scales image by x_scale and y_scale.
ResizeImage: Resizes image to width by height pixels.
RectsOverlap: Returns 1 if the rectangle x1,y1,width1,height1 overlaps the rectangle x2,y2,width2,height2.
ImagesOverlap: Returns 1 if the bounding rectangles of image1 at x1,y1 and image2 at x2,y2 overlap (fast, not pixel-accurate).
ImagesCollide: Returns 1 if frame1 of image1 at x1,y1 and frame2 of image2 at x2,y2 overlap, ignoring transparent pixels.
ImageRectOverlap: Returns 1 if the bounding rectangle of image at x,y overlaps the rectangle at rect_x,rect_y of size rect_width by rect_height.
LoadImageAsync: (ext) Starts loading an image file in the background and returns its handle at once (a single transparent pixel until it arrives); with width and height it is cut into frames like LoadAnimImage (first and count as there, count 0 = all). Use ImageLoaded or PendingLoads to know when it is ready.
ImageLoaded: (ext) Returns 1 when image has loaded (always for other images), 0 while it is loading in the background, -1 if loading failed.
ImageName: (ext) Returns the file image was loaded from, or "" for an image made in the program.

# Buffers and pixels
GetColor: Sets the current drawing colour to the colour of the pixel at x, y in the current buffer. Pixels are read from image and texture buffers, not the screen.
CopyPixel: Copies the pixel at src_x, src_y in src_buffer to dest_x, dest_y in dest_buffer (default the current buffer). The source cannot be the screen.
CopyPixelFast: Same as CopyPixel; copies one pixel from src_buffer to dest_buffer.
BufferWidth: Returns the width of buffer in pixels.
BufferHeight: Returns the height of buffer in pixels.
SaveBuffer: Saves the contents of buffer (the screen too) to an image file; returns 1 on success, 0 on failure.
LoadBuffer: Loads an image file into buffer, drawn from the top-left corner (stretched over the whole screen when buffer is the screen); returns 1 on success, 0 on failure.
BackBuffer: Returns the back buffer, the hidden screen that is drawn to and shown by Flip.
FrontBuffer: Returns the front buffer, the screen that is currently visible.
GraphicsBuffer: Returns the buffer that drawing commands currently draw to.
ImageBuffer: Returns the buffer of frame of image, so it can be drawn to or read.
TextureBuffer: Returns the buffer of frame of texture, so it can be drawn to or read.
SetBuffer: Makes buffer the one 2D drawing commands draw to.
LockBuffer: Locks buffer (default the current one) for fast pixel access with ReadPixelFast and WritePixelFast.
UnlockBuffer: Unlocks a buffer locked with LockBuffer.
ReadPixel: Returns the colour of the pixel at x, y of buffer as an ARGB value.
ReadPixelFast: Returns the colour of the pixel at x, y of a locked buffer as an ARGB value.
WritePixel: Sets the pixel at x, y of buffer to the ARGB colour argb.
WritePixelFast: Sets the pixel at x, y of a locked buffer to the ARGB colour argb.
CopyRect: Copies a width by height rectangle at src_x, src_y of src_buffer to dest_x, dest_y of dest_buffer (both default to the current buffer).

# Tile maps
CreateTileMap: (ext) Creates an empty tile map of width by height tiles, whose tiles are frames of the animation image image, and returns it.
LoadTileMap: (ext) Loads a tile map saved with SaveTileMap from file and draws it with the animation image image (one frame per tile). Returns the tile map handle, or 0 if the file cannot be read.
SaveTileMap: (ext) Saves tile map map (its tiles, terrains and autotile rules) to a text file. Returns 1 on success, 0 on failure.
FreeTileMap: (ext) Frees tile map map.
SetTile: (ext) Sets the cell at column x, row y of tile map map to frame number tile.
GetTile: (ext) Returns the frame number in the cell at column x, row y of tile map map.
TileMapWidth: (ext) Returns the width of tile map map in cells.
TileMapHeight: (ext) Returns the height of tile map map in cells.
TileMapImage: (ext) Changes the animation image whose frames tile map map draws.
TileMapTerrain: (ext) Sets up autotiling for terrain number terrain: its tiles start at frame first_frame of the map's image. mode is 16 (four neighbours, 16 frames) or 47 (eight neighbours, 47 "blob" frames, the default).
AutoTile: (ext) Paints the cell at column x, row y with terrain number terrain, choosing the frame that matches its neighbours and updating the cells around it.
GetTileTerrain: (ext) Returns the terrain number painted with AutoTile in the cell at column x, row y of tile map map.
DrawTileMap: (ext) Draws tile map map with its top-left corner at x,y (pixels, or world coordinates with Camera2D on). Only tiles on screen are drawn.
TileMapCellX: (ext) Returns the column of tile map map under x, given in pixels from the map's left edge.
TileMapCellY: (ext) Returns the row of tile map map under y, given in pixels from the map's top edge.
TileAt: (ext) Returns the frame number of the tile under the point x,y, given in pixels from the map's top-left corner.

# 2D camera
Camera2D: (ext) Turns on the 2D camera: 2D drawing then uses world coordinates, with world point x,y at the centre of the screen, zoom scaling the view (2 = twice as big) and rotation turning it clockwise in degrees.
Camera2DEnable: (ext) Turns the 2D camera on (1) or off (0), for example to draw a HUD in screen coordinates on top.
ScreenToWorld2DX: (ext) Returns the world X coordinate under screen point x,y for the 2D camera.
ScreenToWorld2DY: (ext) Returns the world Y coordinate under screen point x,y for the 2D camera.
WorldToScreen2DX: (ext) Returns the screen X coordinate where world point x,y appears with the 2D camera.
WorldToScreen2DY: (ext) Returns the screen Y coordinate where world point x,y appears with the 2D camera.

# 2D animation
CreateAnim2D: (ext) Creates an animation that plays frames first to last (-1 = last frame) of the animation image image at fps frames a second. mode is 1 loop, 2 ping-pong, 3 play once. Returns the animation handle.
Anim2DPlay: (ext) Starts anim playing frames first to last at fps frames a second, with mode 1 loop, 2 ping-pong or 3 play once.
Anim2DPause: (ext) Pauses anim (pause 1) or resumes it (pause 0).
Anim2DFrame: (ext) Returns the frame number anim is showing now.
Anim2DPlaying: (ext) Returns 1 while anim is playing, 0 when paused or finished.
DrawAnim2D: (ext) Draws the current frame of anim at x,y like DrawImage.
FreeAnim2D: (ext) Frees anim (the image is not freed).

# 2D particles
CreateParticles2D: (ext) Creates a 2D particle system that throws out copies of image (default a soft white dot) and returns its handle: sparks, smoke, dust, rain and explosions for 2D games. Draw it every frame with DrawParticles2D.
PositionParticles2D: (ext) Sets where particles come from, in 2D drawing coordinates.
Particles2DRate: (ext) Makes the system emit per_second particles steadily (0, the default, emits only with EmitParticles2D).
EmitParticles2D: (ext) Throws out count particles at once from the system's position: an explosion or a burst of sparks.
Particles2DLife: (ext) Sets how long particles live, between min and max seconds.
Particles2DSpeed: (ext) Sets how fast particles start, between min and max pixels a second, towards angle degrees (0 right, 90 down, -90 up, the default) spread over spread degrees (360, the default, is every way).
Particles2DGravity: (ext) Sets the pull on particles in pixels a second per second: 0, 200 falls down, 0, -50 rises like smoke.
Particles2DSize: (ext) Sets the particles' scale at birth and at death (1 is the image's own size).
Particles2DSpin: (ext) Sets how fast particles turn, between min and max degrees a second.
Particles2DColor: (ext) Sets the particles' colour and alpha (0-1) at birth; they change smoothly to the fade colour.
Particles2DFadeColor: (ext) Sets the particles' colour and alpha at death (default the same colour, alpha 0: they fade out).
DrawParticles2D: (ext) Moves the particles on by the time since the last call and draws them. Call it once a frame.
Particles2DCount: (ext) Returns how many particles are alive.
FreeParticles2D: (ext) Deletes a 2D particle system.

# 2D physics
Physics2DGravity: (ext) Sets 2D physics gravity to x,y in pixels per second squared (Y down) and starts the 2D physics world.
Physics2DScale: (ext) Sets how many pixels make one physics metre (default 50). Set it before creating bodies.
CreateBody2D: (ext) Creates a 2D physics body at x,y pixels. type is 0 dynamic, 1 static or 2 kinematic. Returns the body handle; give it shapes with Body2DBox and similar commands.
FreeBody2D: (ext) Frees 2D body body and its shapes.
Body2DBox: (ext) Adds a box shape width by height pixels to body, centred at offset_x,offset_y from the body.
Body2DCircle: (ext) Adds a circle shape of radius pixels to body, centred at offset_x,offset_y from the body.
Body2DCapsule: (ext) Adds an upright capsule (pill) shape width by height pixels to body, centred at offset_x,offset_y; good for characters.
Body2DPolygon: (ext) Adds a polygon shape to body from points, a string "x1,y1,x2,y2,..." of at least three points in pixels relative to the body.
Body2DSegment: (ext) Adds a line segment shape from x1,y1 to x2,y2 (pixels, relative to the body) to body.
TileMapBody2D: (ext) Creates a static body with boxes for the solid (non-empty) tiles of tile map map, with the map's top-left corner at x,y. Returns the body handle.
Body2DFriction: (ext) Sets the friction of body's shapes (0 = slippery).
Body2DBounce: (ext) Sets the bounciness (restitution) of body's shapes (0 = no bounce, 1 = full bounce).
Body2DDensity: (ext) Sets the density of body's shapes, which sets its mass.
Body2DSensor: (ext) Makes body's shapes sensors (enable 1) that detect overlaps with Body2DTouching but do not collide.
Body2DFixedRotation: (ext) Stops body from rotating (enable 1) or lets it rotate again (0).
Body2DGravityScale: (ext) Multiplies the gravity on body by scale (0 = no gravity).
Body2DDamping: (ext) Sets the linear and angular damping of body, which slow its movement and spin.
PositionBody2D: (ext) Moves body to x,y in pixels.
RotateBody2D: (ext) Sets body's angle to angle degrees clockwise.
Body2DX: (ext) Returns the X position of body in pixels.
Body2DY: (ext) Returns the Y position of body in pixels.
Body2DAngle: (ext) Returns the angle of body in degrees clockwise.
SetVelocity2D: (ext) Sets the velocity of body to x,y pixels per second.
Body2DVX: (ext) Returns the X velocity of body in pixels per second.
Body2DVY: (ext) Returns the Y velocity of body in pixels per second.
SetSpin2D: (ext) Sets the spin of body in degrees per second (clockwise).
Body2DSpin: (ext) Returns the spin of body in degrees per second.
ApplyForce2D: (ext) Pushes body with force x,y (pixel units) for this step.
ApplyImpulse2D: (ext) Gives body an instant kick x,y (pixel units), like a jump.
ApplyTorque2D: (ext) Applies a turning force torque to body for this step.
Body2DTouching: (ext) Returns 1 if body is touching or overlapping body other, or any body when other is 0.
CountContacts2D: (ext) Returns how many bodies are touching body.
ContactBody2D: (ext) Returns the body touching body with number index (1 to CountContacts2D), or 0.
RayCast2D: (ext) Casts a ray from x1,y1 to x2,y2 and returns the first body it hits, or 0. Read the hit point and normal with RayCast2DX/Y/NX/NY.
RayCast2DX: (ext) Returns the X coordinate in pixels of the point hit by the last RayCast2D.
RayCast2DY: (ext) Returns the Y coordinate in pixels of the point hit by the last RayCast2D.
RayCast2DNX: (ext) Returns the X component of the surface normal at the point hit by the last RayCast2D.
RayCast2DNY: (ext) Returns the Y component of the surface normal at the point hit by the last RayCast2D.
DrawBodies2D: (ext) Draws the outlines of all 2D bodies' shapes in the current colour, for debugging.
DrawBody2D: (ext) Draws frame of image at body's position and angle.

# UI widgets

UIPanel: (ext) Draws a panel (background box) at x,y of size width by height, with an optional title.

UIHover: (ext) Returns 1 if the mouse was over a UI widget (or one is being dragged), so the game can ignore that click.
UITheme: (ext) Sets the UI accent colour (red, green, blue 0-255).

HidePointer: Hides the mouse pointer over the window.
ShowPointer: Shows the mouse pointer again after HidePointer.

CaptureMouse: (ext) Locks the mouse pointer to the window and hides it when enable is 1, for mouse-look; 0 releases and shows it again. MouseXSpeed and MouseYSpeed keep working while captured.
MouseZSpeed: Returns how far the mouse wheel has moved since the last call to MouseZSpeed.
GetMouse: Returns the number of the mouse button clicked since the last check (1 left, 2 right, 3 middle), or 0 if none.

MouseYSpeed: Returns how far the mouse moved vertically since the last call, in pixels.

# Joysticks and gamepads
EnableDirectInput: Accepted for compatibility; enable (1 or 0) is remembered but input always comes straight from the operating system.
DirectInputEnabled: Returns the last value set with EnableDirectInput (1 or 0).
JoyType: Returns the type of controller on port: 0 if none is connected, 2 (analog) for a connected gamepad. Port 0 is the first controller.
CountJoys: (ext) Returns the number of connected joysticks and gamepads.
JoyDown: Returns 1 if button is held down on the controller on port, otherwise 0.
JoyHit: Returns how many times button has been pressed on the controller on port since the last check.
GetJoy: Returns the number of a button pressed on the controller on port since the last check, or 0 if none.
WaitJoy: Waits until a button is pressed on the controller on port and returns its number.
FlushJoy: Forgets all pending joystick button presses.
JoyX: Returns the left stick's horizontal position from -1 (left) to 1 (right) on the controller on port.
JoyY: Returns the left stick's vertical position from -1 to 1 on the controller on port.
JoyZ: Returns the trigger axis from -1 to 1 (right trigger minus left trigger) on the controller on port.
JoyU: Returns the right stick's horizontal position from -1 to 1 on the controller on port.
JoyV: Returns the right stick's vertical position from -1 to 1 on the controller on port.
JoyPitch: Returns the pitch axis in degrees from -180 to 180 (taken from the right stick's vertical position) on the controller on port.
JoyYaw: Returns the yaw axis in degrees from -180 to 180 (taken from the right stick's horizontal position) on the controller on port.
JoyRoll: Returns the roll axis in degrees from -180 to 180 (taken from the triggers) on the controller on port.
JoyHat: Returns the direction of the d-pad (hat) in degrees, 0 for up going clockwise in steps of 45, or -1 if it is not pressed.
JoyXDir: Returns the direction of the joystick's X axis as -1, 0 or 1.
JoyYDir: Returns the direction of the joystick's Y axis as -1, 0 or 1.
JoyZDir: Returns the direction of the joystick's Z axis as -1, 0 or 1.
JoyUDir: Returns the direction of the joystick's U axis as -1, 0 or 1.
JoyVDir: Returns the direction of the joystick's V axis as -1, 0 or 1.
JoyRumble: (ext) Makes a gamepad vibrate for milliseconds (default 300): strong is the heavy low motor and weak the light fast one, 0-1 (weak defaults to strong); port -1 (the default) shakes every gamepad. Returns 1 if a gamepad could rumble.

# Input actions
BindKey: (ext) Binds key (a scancode, like KEY_SPACE) to the action called action, so ActionDown(action) is true while it is held. An action can have any number of keys, buttons and sticks.
BindMouse: (ext) Binds mouse button (1 left, 2 right, 3 middle) to action.
BindJoy: (ext) Binds gamepad button (JOY_A, JOY_START, ...) to action, on any gamepad (port -1, the default) or one port.
BindJoyAxis: (ext) Binds a gamepad stick pushed one way to action: axis "x" or "y" (left stick), "u" or "v" (right stick), "z" (triggers), direction 1 or -1; ActionValue follows how far it is pushed.
BindAction: (ext) Binds an input written as text to action: "key:57", "mouse:1", "joy:1" (or "joy0:1" for the first gamepad only), "axis:x+" ("axis0:y-"), the form LastInput returns.
ClearAction: (ext) Removes all of action's bindings ("" removes every action), for example before binding a new key chosen by the player.
ActionDown: (ext) Returns 1 while any input bound to action is held.
ActionHit: (ext) Returns how many times action was pressed since the last call.
ActionValue: (ext) Returns how far action is pressed, 0-1: 1 for keys and buttons, between for a stick (with a small dead zone).
ActionInputs: (ext) Returns action's bindings as text separated by commas (see BindAction), for showing in a controls menu with InputName.
LastInput: (ext) Returns the input (as text, see BindAction) pressed most recently since the last call, or "": for "press a key for Jump" menus, bind it with BindAction.
InputName: (ext) Returns a name to show players for an input written as text: "Space", "Mouse left", "Gamepad A", "Left stick right".
SaveActions: (ext) Writes every action's bindings to file, one action=inputs line each.
LoadActions: (ext) Reads action bindings from file (each action named there replaces its bindings) and returns 1, or 0 if the file does not exist.

# Sound
LoadSound: Loads a sound from file (WAV, OGG, MP3 or FLAC) and returns it, or 0 if it cannot be loaded.
Load3DSound: Loads a sound from file for 3D positional playback with EmitSound and returns it.
FreeSound: Frees sound.
LoopSound: Makes sound loop when it is played.
SoundVolume: Sets sound's volume, from 0 (silent) to 1 (full).
SoundPan: Sets sound's pan, from -1 (left) to 1 (right).
SoundPitch: Sets the playback rate of sound, in Hz (samples per second).
PlaySound: Plays sound and returns the channel it plays on.
PlayCDTrack: Kept so older programs still run: CD audio is not supported, so it does nothing and returns 0.
PlayMusic: Plays a music file (streamed from disk) once, or looping when mode is 1, and returns its channel, or 0 if it cannot be loaded.
StopChannel: Stops the sound playing on channel.
PauseChannel: Pauses the sound playing on channel.
ResumeChannel: Resumes a channel paused with PauseChannel.
ChannelVolume: Sets the volume of channel, from 0 (silent) to 1 (full).
CreateAudioBus: (ext) Creates an audio bus (a mixer channel that sounds play into) feeding parent (0, the default, is the master bus everything ends in) and returns its handle; name is optional. Use one bus each for music, effects and voices to set their volumes apart, or to give a group of sounds a reverb or filter.
BusVolume: (ext) Sets the volume of bus (0 is the master bus), from 0 (silent) to 1 (full); above 1 is louder.
BusReverb: (ext) Gives bus a reverb, the echoes of a room, hall or cave: decay_seconds is how long the echoes last (0 removes the reverb), dry how much of the original sound is kept (0-1), brightness the highest frequency the echoes keep in Hz (lower is duller).
BusFilter: (ext) Gives bus a filter of kind FILTER_LOWPASS (muffles: underwater, behind a wall), FILTER_HIGHPASS (thins: a radio, a telephone), FILTER_BANDPASS, FILTER_LOWSHELF, FILTER_HIGHSHELF or FILTER_ALLPASS at frequency in Hz, with quality (the width around it) and gain; FILTER_NONE removes it. The filter comes before the reverb.
SoundBus: (ext) Makes the channels that sound plays from now on go into bus.
ChannelBus: (ext) Moves a playing channel into bus.
ChannelPan: Sets the pan of channel, from -1 (left) to 1 (right).
ChannelPitch: Sets the playback rate of channel, in Hz.
ChannelPlaying: Returns 1 if channel is playing, otherwise 0.
CreateListener: Creates the 3D sound listener (the player's ears) as a child of the entity parent, usually the camera, and returns it; rolloff_factor and distance_scale control how sound fades with distance, doppler_scale how much moving sounds change pitch.
EmitSound: Plays a 3D sound from the position of entity and returns its channel.
LoadSoundAsync: (ext) Starts loading a sound file in the background and returns its handle at once (silent until it arrives); spatial 1 makes it a 3D sound like Load3DSound. Use SoundLoaded or PendingLoads to know when it is ready.
SoundLoaded: (ext) Returns 1 when sound has loaded (always 1 for sounds loaded with LoadSound or Load3DSound), 0 while it is loading in the background, -1 if loading failed.
SoundName: (ext) Returns the file sound was loaded from.

# Entities
EntityClass: Returns the kind of entity as a string, such as "Pivot", "Camera", "Light" or "Mesh".
EntityAutoFade: Makes entity fade out as the camera gets between near and far units away; far 0 or less turns fading off.
ClearWorld: Frees all entities, brushes and/or textures, as chosen by entities, brushes and textures (all default 1).
CreatePivot: Creates an invisible pivot entity, useful as a parent or marker, and returns its handle; parent is optional.
CreateCube: Creates a cube from -1 to 1 on each axis and returns its handle; parent is optional.
CreateSphere: Creates a sphere of radius 1 with segments detail (default 8) and returns its handle; parent is optional.
CreateCylinder: Creates a cylinder of radius 1 and height 2 with segments detail and returns its handle; solid 0 leaves the ends open. parent is optional.
CreateCone: Creates a cone of radius 1 and height 2 with segments detail and returns its handle; solid 0 leaves the base open. parent is optional.
CreatePlane: Creates an infinite flat plane at Y 0 facing up, with segments detail, and returns its handle; parent is optional.
EntityScaleX: (ext) Returns the X scale of entity; global 1 gives the world scale including its parents.
EntityScaleY: (ext) Returns the Y scale of entity; global 1 gives the world scale including its parents.
EntityScaleZ: (ext) Returns the Z scale of entity; global 1 gives the world scale including its parents.
CopyEntity: Makes a copy of entity (and its children), optionally attached to parent, and returns the new entity.
FreeEntity: Deletes entity and all its children.
EntityParent: Attaches entity to parent (0 detaches it). With global 1 (default) the entity keeps its world position and rotation; with 0 it keeps its local ones.
GetParent: Returns the parent of entity, or 0 if it has none.
CountChildren: Returns the number of direct children of entity.
GetChild: Returns child number index (counting from 1) of entity, or 0 if there is none.
FindChild: Searches entity's children and their descendants for an entity called name and returns it, or 0 if not found.
NameEntity: Sets the name of entity.
EntityName: Returns the name of entity.
HideEntity: Hides entity and its children so they are not drawn and take no part in collisions or picking.
ShowEntity: Shows an entity hidden with HideEntity.
EntityHidden: (ext) Returns 1 if entity has been hidden with HideEntity, otherwise 0.

# Transforms
PositionEntity: Places entity at x, y, z, relative to its parent unless global is 1.
MoveEntity: Moves entity by x, y, z along its own axes (so z moves it forward the way it faces).
TranslateEntity: Moves entity by x, y, z along the world axes (or its parent's axes when global is 0), ignoring its own rotation.
RotateEntity: Sets entity's rotation to pitch, yaw, roll in degrees, relative to its parent unless global is 1.
TurnEntity: Turns entity by pitch, yaw, roll degrees from its current rotation.
ScaleEntity: Sets entity's scale on each axis to x_scale, y_scale, z_scale (1 is normal size).
PointEntity: Rotates entity to face target entity, with roll degrees of roll.
LookAt: (ext) Rotates entity to face the world position x, y, z, with roll degrees of roll.
CameraLookAt: (ext) Rotates camera to face the world position x, y, z, with roll degrees of roll; the same as LookAt.
EntityX: Returns entity's X position, relative to its parent or in world space when global is 1.
EntityY: Returns entity's Y position, relative to its parent or in world space when global is 1.
EntityZ: Returns entity's Z position, relative to its parent or in world space when global is 1.
EntityPitch: Returns entity's pitch in degrees, relative to its parent or in world space when global is 1.
EntityYaw: Returns entity's yaw in degrees, relative to its parent or in world space when global is 1.
EntityRoll: Returns entity's roll in degrees, relative to its parent or in world space when global is 1.

# Tweens
TweenPosition: (ext) Moves entity smoothly from where it is to x, y, z (local, like PositionEntity) over seconds, along easing curve ease (default EASE_IN_OUT): doors, lifts, menus, pickups.
TweenRotation: (ext) Turns entity smoothly to pitch, yaw, roll (like RotateEntity) over seconds, along easing curve ease.
TweenScale: (ext) Scales entity smoothly to x_scale, y_scale, z_scale over seconds, along easing curve ease: things that pop up or shrink away.
TweenAlpha: (ext) Fades entity smoothly to alpha (0-1) over seconds, along easing curve ease.
TweenColor: (ext) Changes entity's colour smoothly to red, green, blue over seconds, along easing curve ease.
Tweening: (ext) Returns 1 while entity has a tween running (entity 0: while any entity has).
StopTweens: (ext) Stops entity's tweens where they are (entity 0, the default: every tween).

# Vectors and maths on entities
TFormPoint: Transforms the point x, y, z from the space of source_entity to the space of dest_entity (0 means world space); read the result with TFormedX, TFormedY, TFormedZ.
TFormVector: Transforms the direction x, y, z from the space of source_entity to the space of dest_entity (0 means world space), ignoring position; read the result with TFormedX, TFormedY, TFormedZ.
TFormNormal: Like TFormVector but the result is normalised to length 1; read it with TFormedX, TFormedY, TFormedZ.
TFormedX: Returns the X of the result of the last TFormPoint, TFormVector or TFormNormal.
TFormedY: Returns the Y of the result of the last TFormPoint, TFormVector or TFormNormal.
TFormedZ: Returns the Z of the result of the last TFormPoint, TFormVector or TFormNormal.
VectorYaw: Returns the yaw in degrees of the direction x, y, z.
VectorPitch: Returns the pitch in degrees of the direction x, y, z.
DeltaYaw: Returns the yaw in degrees src_entity would need to turn to face dest_entity.
DeltaPitch: Returns the pitch in degrees src_entity would need to turn to face dest_entity.
AlignToVector: Turns entity so its axis (1 X, 2 Y, 3 Z) points along vector_x, vector_y, vector_z; rate from 0 to 1 sets how far it turns (1 aligns fully).
GetMatElement: Returns the element at row and column (0 to 2) of entity's world rotation and scale matrix.
EntityDistance: Returns the distance in world units between source_entity and destination_entity.

# Cameras
CameraClsMode: Sets whether camera clears the colour buffer (cls_color) and depth buffer (cls_zbuffer) before rendering; 1 clears, 0 keeps what was there, so the camera's picture is laid over the other cameras (also inside its viewport). Cameras in scenes after the first always work like cls_color 0.
CreateCamera: Creates a camera and returns its handle; parent is optional.
CameraClsColor: Sets the colour camera clears the background to, with red, green, blue from 0 to 255.
CameraRange: Sets the nearest and farthest distances camera can see (defaults 1 and 1000).
CameraZoom: Sets camera's zoom factor; 1 is the default, higher values zoom in.
CameraViewport: Sets the area of the screen camera draws into, as x, y, width, height in pixels.
CameraProjMode: Sets camera's projection: 0 off (draws nothing), 1 perspective (default), 2 orthographic.
CameraFogMode: Sets camera's fog: 0 off, 1 linear fog.
CameraFogColor: Sets camera's fog colour, with red, green, blue from 0 to 255.
CameraFogRange: Sets the distances where camera's fog starts (near) and becomes solid (far).
CameraShake: (ext) Shakes camera's picture for a hit, explosion or landing: strength 1 (the default) is a solid jolt, more is stronger; it dies away over seconds (default 0.4). The camera itself does not move, so picks and its position are unaffected.

# Lights
AmbientLight: Sets the colour of the ambient light that lights every surface equally, using red, green and blue values 0-255.
CreateLight: Creates a light and returns its handle; type is 1 directional (default), 2 point or 3 spot. parent is an optional parent entity.
LightMesh: Lights a mesh by adding colour to its vertex colours, using red, green, blue 0-255; with range above 0 the light is a point at light_x, light_y, light_z that fades with distance, otherwise the whole mesh is lit evenly.
LightColor: Sets light's colour, with red, green, blue from 0 to 255 (higher values make it brighter).
LightRange: Sets how far light reaches, in world units.
LightConeAngles: Sets a spot light's inner (full brightness) and outer cone angles, in degrees.
SetLightDirection: (ext) Turns light so it shines along the direction x, y, z.
SetEntityDirection: (ext) Turns entity so it faces along the direction x, y, z.
LightShadows: (ext) Turns real-time shadows on (enable 1) or off (0) for light.
LightIntensity: (ext) Sets how bright light is, multiplying its colour: 1 is normal, above 1 brighter than white (a lamp that lights up a room, the sun at noon), 0 off.
LightScatter: (ext) Sets the glow a point or spot light makes in the air around it (light shafts in dusty or foggy air): amount is a multiple of the normal strength (0 turns it off, 3 is thick haze), red, green, blue tint it. Needs EFFECT_LIGHT_SCATTER, on at high and ultra quality.
LightCookie: (ext) Projects texture through a spot light like a slide, multiplying its light: dark parts block light (window bars, leaves), coloured parts tint it (stained glass); 0 removes it. Affects surfaces with the standard (PBR) material.
LightShadowBias: (ext) Sets the shadow bias of one light: raise it a little if lit surfaces show stripes or speckles of shadow ("shadow acne"); too high and shadows come loose from their objects.

# Materials and textures
LoadAnimTexture: Loads an image file holding several animation frames of frame_width by frame_height pixels as one texture, using frame_count frames starting at first_frame; returns its handle or 0 on failure.
TextureFilter: Applies texture flags automatically to every texture loaded later whose file name contains match_text.
ClearTextureFilters: Removes all texture filters set with TextureFilter.
EntityColor: Sets entity's colour, with red, green, blue from 0 to 255.
EntityAlpha: Sets entity's transparency, from 0 (invisible) to 1 (solid).
LoadTextureAsync: (ext) Starts loading a texture from file in the background and returns it at once; it is plain white until the image has loaded. Check progress with TextureLoaded.
TextureLoaded: (ext) Returns 1 when texture has finished loading, 0 while it is still loading and -1 if loading failed.
LoadTexture: Loads a texture from file with the given flags (1 colour, 2 alpha, 4 masked, 8 mipmapped, 16/32 clamp U/V, 64 sphere map, 128 cube map...) and returns it, or 0 if the file cannot be loaded.
CreateTexture: Creates a blank texture of width by height pixels with the given flags and number of animation frames, and returns it.
FreeTexture: Frees texture; entities that use it keep it until they no longer need it.
TextureWidth: Returns the width of texture in pixels.
SetCubeFace: Chooses which face of a cube map texture (0 left, 1 front, 2 right, 3 back, 4 up, 5 down) its texture buffer draws to.
SetCubeMode: Sets how a cube map texture is used: 1 reflection (default), 2 diffuse lighting, 3 specular lighting.
TextureHeight: Returns the height of texture in pixels.
TextureName: Returns the file name texture was loaded from.
ScaleTexture: Scales texture's coordinates by u_scale and v_scale (values above 1 make the texture smaller and repeat more).
PositionTexture: Offsets texture's coordinates by u_position and v_position.
RotateTexture: Rotates texture by angle degrees.
TextureBlend: Sets how texture combines with the layers below it: 0 none, 1 alpha, 2 multiply (default), 3 add, 4 dot3, 5 multiply by 2.
TextureCoords: Chooses which UV set texture uses: 0 the first (default) or 1 the second.
EntityTexture: Applies texture to entity, using animation frame frame, in texture layer index.
EntityNormalMap: (ext) Gives entity a normal map texture for per-pixel lighting detail; 0 removes it.
EntityShininess: Sets entity's specular shininess, from 0 (none) to 1 (very shiny).
EntityBlend: Sets how entity is blended with what is behind it: 1 alpha, 2 multiply, 3 add.
EntityFX: Sets special effects flags for entity: 1 full bright, 2 use vertex colours, 4 flat shading, 8 no fog, 16 no back-face culling, 32 force alpha blending.
EntityOrder: Sets the drawing order of entity: non-zero values are drawn after the main scene with depth buffering off, lower values in front.

# PBR materials
EntityMetallic: (ext) Sets how metallic entity's material is, from 0 (not metal) to 1 (metal).
EntityRoughness: (ext) Sets the roughness of entity's material, from 0 (smooth and glossy) to 1 (rough and matte).
EntityEmissive: (ext) Makes entity glow with the colour red, green, blue (0-255) times intensity; all zero turns the glow off. Glow shows strongly with the bloom post effect.
EntityMetallicMap: (ext) Gives entity a texture controlling how metallic each part of it is; 0 removes it.
EntityRoughnessMap: (ext) Gives entity a texture controlling the roughness of each part of it; 0 removes it.
EntityEmissiveMap: (ext) Gives entity a texture controlling which parts of it glow; 0 removes it.
EntityAOMap: (ext) Gives entity an ambient occlusion texture that darkens creases and corners; 0 removes it.
EntityLightmap: (ext) Gives entity a lightmap texture, read with the mesh's second UV set; 0 removes it.
BakeLightmaps: (ext) Works out soft lighting for still scenery and stores it in lightmap textures, then returns how many surfaces were baked: sky light (the AmbientLight colour) dimmed in corners and under things, and light bounced off nearby surfaces in their colours. texels_per_unit sets the detail (default 4 per unit), quality 0 fast, 1 normal, 2 best, direct 1 also bakes the lights' direct light with shadows (then turn those lights off), entity limits it to one entity and its children. Only meshes with the standard (PBR) material are baked; it may take seconds. Turn AmbientLight down afterwards so the baked sky light shows.
ClearLightmaps: (ext) Removes baked light from entity and its children, or from everything (0, the default).
EntityHeightMap: (ext) Gives entity a height map texture (white is high) for parallax mapping, with depth scale (default 0.08); 0 removes it.
CreatePBRMaterial: (ext) Creates a physically based material (metallic/roughness, normal maps, parallax, emission, environment reflections, shadows) and returns it. Draw entities with it using EntityMaterial.
SetAlbedo: (ext) Sets the base colour of material, red, green, blue, alpha 0-255.
SetAlbedoMap: (ext) Sets the base colour texture of material.
SetMetallic: (ext) Sets how metallic material is, 0 (plastic, stone) to 1 (metal).
SetRoughness: (ext) Sets how rough material is, 0 (mirror-smooth) to 1 (matte).
SetEmissive: (ext) Makes material glow with red, green, blue 0-255 times strength (glows more with bloom).
SetNormalMap: (ext) Sets the normal map of material, with strength to soften or exaggerate the bumps.
SetMetallicMap: (ext) Sets a texture whose red channel scales the metallic value of material across its surface.
SetRoughnessMap: (ext) Sets a texture whose red channel scales the roughness of material across its surface.
SetAOMap: (ext) Sets the ambient occlusion texture of material (dark where ambient light cannot reach).
SetEmissiveMap: (ext) Sets the texture that colours the glow of material.
SetOpacityMap: (ext) Sets a texture whose red channel is the opacity of material; mode OPACITY_CUTOUT (default) cuts holes and keeps shadows, OPACITY_BLEND blends, OPACITY_OPAQUE ignores it.
SetOpacity: (ext) Sets the opacity of material, 0-1; mode OPACITY_BLEND (default) blends, OPACITY_CUTOUT cuts below 0.5.
SetHeightMap: (ext) Sets the height map of material (white = high) for parallax mapping, with its depth scale; texture 0 turns it off.
SetEnvironmentMap: (ext) Sets the cube map material reflects, with intensity.
SetReflectionIntensity: (ext) Sets how strongly material reflects its environment map.
SetFresnel: (ext) Sets how much stronger reflections of material get at glancing angles, 0 (not at all) to 1 (fully).
SetParallaxScale: (ext) Sets the depth of material's parallax mapping.
SetMaterialWorkflow: (ext) Sets the workflow of material: WORKFLOW_METALLIC, or WORKFLOW_SPECULAR with the specular colour red, green, blue 0-255.

VertexDataValue: (ext) Returns one component (0 to 3) of data slot (0 to 3) of vertex index of surface, as set with VertexData.
VertexTexCoords: Sets the texture coordinates u, v, w of vertex index of surface in coordinate set coord_set (0 or 1).

VertexGreen: Returns the green component (0-255) of the colour of vertex index of surface.

# Models and animation
CaptureWorld: Records the position, rotation and scale of every entity, for RenderWorld tweening.
AddAnimSeq: Adds an empty keyframe animation sequence of length frames to entity and returns its number; fill it with SetAnimKey.
SetAnimKey: Stores entity's current position, rotation and/or scale (chosen by pos_key, rot_key, scale_key) as a key at frame of its last added sequence.
LoaderMatrix: Sets the matrix applied to models loaded from files with file_extension; the three rows xx,xy,xz / yx,yy,yz / zx,zy,zz are the new X, Y and Z axes.
LoadAnimSeq: Loads the animations from another model file and adds them to the animated model entity (retargeted to its skeleton); returns the number of the first new sequence, or -1 on failure.
LoadMesh: Loads a glTF (.gltf/.glb), FBX or saved scene file as a single entity and returns its handle, or 0 on failure; parent is optional. Older formats (.b3d, .x, .3ds) are not supported.
LoadMeshAsync: (ext) Starts loading a model file in the background and returns its entity at once; the model appears in it when loaded. parent is optional.
EntityLoaded: (ext) Returns 1 if the model of entity has finished loading (always for other entities), 0 while it is still loading, -1 if loading failed.
PendingLoads: (ext) Returns the number of background model and texture loads still in progress.
LoadAnimMesh: Loads an animated model (with its bone hierarchy and animations) from file and returns it as an entity, optionally attached to parent. Returns 0 if the file cannot be loaded.
Animate: Starts animating entity: mode 0 stops, 1 loops, 2 ping-pongs, 3 plays once; speed scales playback, sequence picks the animation sequence and transition is the number of frames to blend from the current pose.
SetAnimTime: Jumps entity's animation to time (in frames) in the given sequence.
Animating: Returns 1 if entity is currently animating, otherwise 0.
AnimTime: Returns the current time (frame) of entity's animation.
AnimSeq: Returns the animation sequence entity is currently playing.
AnimLength: Returns the length in frames of entity's current animation sequence.
ExtractAnimSeq: Creates a new animation sequence from frames first_frame to last_frame of sequence anim_seq and returns the new sequence's number.
CountAnimSeqs: (ext) Returns how many animation sequences entity has (0 if it is not animated).
AnimLayer: (ext) Plays sequence on animation layer (1-8) of entity on top of its main animation, blended in by weight (0-1); mode and speed work like Animate. bone limits the layer to that bone and everything below it ("" = the whole model), e.g. the upper body shooting while the legs run; a whole-body layer at weight 0.3 mixes the two animations 70/30.
AnimLayerWeight: (ext) Changes how strongly animation layer of entity is blended in, from 0 (not at all) to 1 (fully); change it a little each frame to fade a layer in or out.
AnimLayerStop: (ext) Removes animation layer from entity.
CreateBlendSpace: (ext) Creates an empty blend space and returns its handle; add sequences to it with BlendSpacePoint and play it with AnimBlend or AddBlendState.
BlendSpacePoint: (ext) Places animation sequence at point x (and y) of blend space, e.g. idle at 0, walk at 1 and run at 3 for speed. Points that all share one y form a line; otherwise they form a plane (speed and direction).
AnimBlend: (ext) Plays blend space on entity, mixing its sequences for the point x,y (call it again each frame with new values; the mix changes smoothly). All sequences stay at the same point of their cycle so steps stay in step. speed scales playback; transition crossfades from the previous animation over that many frames.
AddAnimState: (ext) Adds a state called name to entity's animation state machine that plays sequence with mode (1 loop, 2 ping-pong, 3 once) and speed; returns the state's number.
AddBlendState: (ext) Adds a state called name to entity's animation state machine that plays blend space, its position taken each frame from the parameters param_x (and param_y) set with SetAnimParam; returns the state's number.
AddAnimTransition: (ext) Makes entity's state machine switch from state from ("*" or "" for any state) to state to when condition holds, crossfading over duration frames. condition is "" (at once), "end" (the state's one-shot animation has finished) or a comparison of a parameter such as "speed > 0.5" (operators > < >= <= = <>).
SetAnimParam: (ext) Sets parameter name of entity's animation state machine to value; transitions and blend states read it.
AnimParam: (ext) Returns the value of parameter name of entity's animation state machine (0 if never set).
StartAnimStates: (ext) Starts entity's animation state machine in state; from then on UpdateWorld takes its transitions by itself.
AnimStateName: (ext) Returns the name of the state entity's animation state machine is in, or "" if it has none.
AnimRootMotion: (ext) Root motion: the movement of the root bone in entity's animation moves the entity instead, so its feet do not slide (for animations made moving forward rather than in place). bone picks the root bone ("" = the model's topmost moving bone); enable 0 turns it off; keep_y 1 leaves up and down movement in the animation.
CreateTrack: (ext) Creates a property track that animates property of entity and returns its handle. property is position, rotation, scale, color, alpha, shininess, emissive, lightcolor, lightrange, camerazoom, fogrange, texture (offset of the entity's first texture) or texturerotation; add keys with TrackKey.
TrackKey: (ext) Sets the value of track at frame (1/60 s each): value1 to value3 as the property needs (x,y,z; red,green,blue; near,far; u,v; or one value). Values between keys change in a straight line.
PlayTrack: (ext) Plays track from its start: mode 1 loops, 2 goes back and forth, 3 plays once, 0 stops; speed scales it (negative plays backwards). Tracks advance in UpdateWorld.
SetTrackTime: (ext) Stops track and sets its property to the value at frame.
TrackTime: (ext) Returns the current frame of track.
TrackPlaying: (ext) Returns 1 while track is playing, 0 when stopped or finished.
FreeTrack: (ext) Deletes track; the property keeps its last value.

# Terrain
CreateTerrain: Creates a flat terrain of grid_size by grid_size squares (a power of 2) and returns its handle; parent is optional.

TerrainSize: Returns the grid size of terrain.

TerrainShading: Accepted for compatibility; terrain shading is handled by the GPU.
TerrainLayer: (ext) Gives terrain a texture for layer 0 (the base, the same as EntityTexture) to 3. Layers 1 to 3 are painted over the base with PaintTerrain or LoadTerrainLayers (grass, rock, sand, snow...); scale them with ScaleTexture.

ErodeTerrain: (ext) Erodes terrain with simulated rain: droplets raindrops each run downhill, taking soil from the slopes and leaving it where they slow down, which carves gullies and ridges into mountains and fills valleys. More droplets erode more (try 50000 to 300000 for a 256 terrain); the same seed gives the same result. Set the terrain's ScaleEntity first: steepness depends on its proportions.
ThermalErodeTerrain: (ext) Lets slopes of terrain steeper than max_angle degrees crumble down until they are no steeper, repeated iterations times: softens sharp peaks and builds scree at the foot of cliffs. Set the terrain's ScaleEntity first.
ModifyTerrainLayer: (ext) Sets how much painted layer (1-3) covers terrain at grid point grid_x, grid_z, from 0 to 1, without changing the other layers (like ModifyTerrain for heights; layers above still cover it). Useful for painting by height or slope in a loop.
TerrainLayerWeight: (ext) Returns how much of layer (0-3) shows on terrain at world position x, z, from 0 to 1 (for footstep sounds, placing trees on grass, slowing down in sand).
LoadTerrainLayers: (ext) Paints terrain's layers 1, 2 and 3 from the red, green and blue of an image file (a splat map, as painted in another program), stretched over the whole terrain; the top of the image is the far (+Z) edge.

CreateHingeJoint2D: (ext) Joins 2D bodies body1 and body2 with a hinge (pin) at x,y pixels that lets them turn. Returns the joint handle.
CreateFixedJoint2D: (ext) Locks 2D bodies body1 and body2 together at x,y pixels. Returns the joint handle.
CreateSliderJoint2D: (ext) Joins 2D bodies body1 and body2 with a slider at x,y that lets them slide along a line at angle degrees. Returns the joint handle.
FreeJoint2D: (ext) Removes 2D joint joint.
JointMotor2D: (ext) Drives a 2D hinge or slider joint at speed (degrees or pixels per second), pushing with at most max_force.
JointTarget2D: (ext) Pulls a 2D hinge or slider joint like a spring to target (degrees or pixels) with stiffness, pushing with at most max_force.
JointMotorOff2D: (ext) Turns off the motor or target of 2D joint joint.
JointLimits2D: (ext) Limits a 2D hinge (degrees) or slider (pixels) joint to between min and max; enable 0 removes the limits.
JointAngle2D: (ext) Returns how far a 2D hinge joint has turned since it was made, in degrees clockwise.
JointPosition2D: (ext) Returns how far a 2D slider joint has slid since it was made, in pixels.

# AI and pathfinding
CreateNavMesh: (ext) Makes a navigation mesh (the ground characters can walk on) from entity's mesh, in world space, keeping triangles that slope at most max_slope degrees; returns its handle. Use a mesh made for walking, or a level's floor. Also called CreateNavigationMesh.
GenerateNavMesh: (ext) Makes a navigation mesh by looking down on the pickable entities (EntityPickMode) over the area from x, z to x + width, z + depth every cell_size units: ground that slopes at most max_slope degrees is kept, and neighbouring points join when their heights differ by at most step_height, so walls and boxes become holes. top is the height to look down from. Returns its handle.
NavMeshEntity: (ext) Creates a mesh entity showing navmesh (just above it) and returns it, for checking what is walkable; colour it with EntityColor and EntityAlpha.
NavMeshTriangles: (ext) Returns how many triangles navmesh has.
NavMeshX: (ext) Returns the X of the point on navmesh closest to x, y, z (use with NavMeshY and NavMeshZ to keep something on walkable ground).
NavMeshY: (ext) Returns the Y of the point on navmesh closest to x, y, z.
NavMeshZ: (ext) Returns the Z of the point on navmesh closest to x, y, z.
FreeNavMesh: (ext) Frees navmesh and the agents using it.
FindPath: (ext) Finds the shortest way over navmesh from x1, y1, z1 to x2, y2, z2 (A* with corners cut where the way is clear) and returns a path handle, or 0 if there is no way. Read it with PathPoints and PathX/Y/Z.
PathPoints: (ext) Returns how many points path has (from FindPath, FindGridPath or AgentPath).
PathX: (ext) Returns the X of point index (from 0) of path; for a grid path, the column.
PathY: (ext) Returns the Y of point index (from 0) of path; for a grid path, the row.
PathZ: (ext) Returns the Z of point index (from 0) of path.
PathLength: (ext) Returns the length of path, along its points.
FreePath: (ext) Frees path.
CreatePathGrid: (ext) Creates a grid of width x height cells for A* pathfinding (2D games, strategy maps) and returns its handle. Every cell starts with cost 1.
SetPathCost: (ext) Sets how hard cell x, y of grid is to cross: 1 normal, higher numbers slower (mud, forest), 0 blocked.
PathCost: (ext) Returns the cost of cell x, y of grid (0 = blocked).
FindGridPath: (ext) Finds the cheapest way over grid from cell x1, y1 to cell x2, y2 with A* and returns a path handle (PathX = column, PathY = row), or 0 if there is no way. With diagonal 1 it also moves diagonally, but never cuts past a blocked corner.
TileMapPathGrid: (ext) Creates a path grid the size of tile map map: empty cells cost 1, cells with a tile are blocked (the same tiles TileMapBody2D makes solid). Returns its handle.
FreePathGrid: (ext) Frees grid.
CreateAgent: (ext) Makes entity (a top-level entity) an agent that walks over navmesh by itself at speed units a second, keeping radius away from other agents; returns its handle. Agents move in UpdateWorld, turn to face where they go, and keep their height above the navigation mesh.
AgentMoveTo: (ext) Sends agent to x, y, z: it finds the way and walks there. AgentArrived tells when it is there.
AgentFollow: (ext) Makes agent keep walking towards entity, stopping when within distance, and finding a new way as the entity moves. entity 0 stops following.
AgentStop: (ext) Stops agent where it is.
AgentArrived: (ext) Returns 1 when agent has reached where it was sent (or is close enough to what it follows) or is not going anywhere, 0 while it is walking.
AgentDistance: (ext) Returns how far agent still has to walk along its path.
AgentSpeed: (ext) Sets how fast agent walks, in units a second.
AgentTurnSpeed: (ext) Sets how fast agent turns to face where it goes, in degrees a second (default 360; 0 does not turn it).
AgentRadius: (ext) Sets how far agent keeps from other agents.
AgentEntity: (ext) Returns the entity agent moves.
AgentPath: (ext) Returns a copy of the path agent is walking as a path handle (free it with FreePath), or 0 if it has none.
FreeAgent: (ext) Frees agent; its entity stays where it is.
CreateBehavior: (ext) Creates an empty behaviour tree for decision making and returns its handle; add nodes with BehaviorSelector, BehaviorSequence, BehaviorInvert, BehaviorIf and BehaviorDo (the first node without a parent is the root).
LoadBehavior: (ext) Loads a behaviour tree from a text file and returns its handle. Each line is a node, children indented under their parent: selector, sequence, invert, if <condition>, do <action>; a semicolon starts a comment.
BehaviorFromText: (ext) Makes a behaviour tree from text written like a LoadBehavior file (lines separated by Chr(10)) and returns its handle.
BehaviorSelector: (ext) Adds a selector node under parent (0 = top level) to behavior and returns its node number: it tries its children in order until one succeeds or is running, so the first that applies wins.
BehaviorSequence: (ext) Adds a sequence node under parent to behavior and returns its node number: it runs its children in order while they succeed.
BehaviorInvert: (ext) Adds an invert node under parent to behavior and returns its node number: its one child's success counts as failure and failure as success.
BehaviorIf: (ext) Adds a condition node under parent to behavior and returns its node number. The condition compares parameters set with SetBehaviorParam and numbers, like "dist < 10" or "health >= max" (< <= > >= = <>), or is just a parameter name (true when not 0).
BehaviorDo: (ext) Adds an action node under parent to behavior and returns its node number. The action is a name the program acts on when BehaviorAction returns it.
FreeBehavior: (ext) Frees behavior and stops every character using it.
SetBehavior: (ext) Makes entity (or any number that names a character) use behavior; 0 removes it. Each character keeps its own parameters and progress.
SetBehaviorParam: (ext) Sets parameter name of entity's behaviour to value, for its conditions to compare (names are not case-sensitive; parameters not set are 0).
BehaviorParam: (ext) Returns parameter name of entity's behaviour.
BehaviorAction: (ext) Evaluates entity's behaviour tree and returns the action to do now, or "" if none. Conditions are checked every time, so a more important branch takes over as soon as it applies. Do the action every frame until it is finished, then call BehaviorResult.
BehaviorResult: (ext) Tells entity's behaviour that the current action finished: success 1 (the default) if it worked, 0 if it failed, so sequences go on to their next step and selectors try their next choice.

# Rendering effects
CreateDecal: (ext) Creates a decal that projects texture onto the scene inside its box (size it with ScaleEntity) and returns its handle; parent is optional.
CreateReflectionProbe: (ext) Creates a reflection probe and returns its handle: it takes a picture of the scene in all directions (resolution pixels square per face, default 256), and while the camera is inside its box (one unit across, size it with ScaleEntity) shiny PBR surfaces reflect that picture and are lit by it. The picture is taken once, on the next frame; parent is optional.
ProbeRange: (ext) Sets the nearest and farthest distances probe sees (default 0.1 to 1000); nearer limits draw faster.
ProbeMode: (ext) Sets when probe takes its picture: mode 0 once (UpdateProbe takes it again), 1 every frame (for moving things; draws the scene six more times).
UpdateProbe: (ext) Makes probe take its picture again on the next frame, after the scene around it changed.
ProbeOffset: (ext) Moves the point the probe takes its picture from by x, y, z (world directions) away from the probe's position, without moving its box.
ProbeTexture: (ext) Returns the picture of probe as a cube map texture for custom shaders (ShaderTexture, ShaderSetCubeMap). An entity given it with ShaderTexture is left out of the probes' pictures.
EnvironmentLighting: (ext) Chooses where ambient light and reflections come from: mode 0 the AmbientLight colour (the default: no reflections), 1 the sky box, or the reflection probe around the camera, so shiny surfaces reflect it; brightness scales it. CreateReflectionProbe switches to 1.
CreateEmitter: (ext) Creates a particle emitter using texture for the particles and returns its handle; parent is optional.
EmitterRate: (ext) Sets how many particles emitter makes per_second.
EmitterMax: (ext) Limits emitter to count particles alive at once; 0 means no limit.
EmitterLife: (ext) Sets the lifetime of each particle of emitter to a random value between min and max seconds.
EmitterVelocity: (ext) Sets the starting velocity x, y, z of particles of emitter in units per second, randomised by up to spread on each axis.
EmitterSize: (ext) Sets the starting size of particles of emitter, and grow, how much they grow per second.
EmitterSpin: (ext) Sets the spin speed of particles of emitter to a random value between min and max.
EmitterColor: (ext) Sets the colour particles of emitter start with, as red, green, blue and alpha (0-255, alpha default 255).
EmitterFadeColor: (ext) Sets the colour particles of emitter fade to by the end of their life, as red, green, blue and alpha (0-255, alpha default 0).
EmitterGravity: (ext) Sets the acceleration x, y, z applied to particles of emitter, in units per second squared.
EmitterShape: (ext) Sets where particles of emitter are born: shape 0 is a sphere of radius width, 1 is a box of width, height, depth.
EmitterSoftness: (ext) Sets how softly particles of emitter fade where they meet scene geometry; 0 turns soft particles off.
EmitterLocal: (ext) With enable 1, particles of emitter move with it; with 0 (default) they stay where they were born, leaving trails.
EmitterEnable: (ext) Starts (enable 1) or stops (0) emitter making new particles.
EmitterClear: (ext) Removes all particles of emitter at once.
EntityLOD: (ext) Makes the level entity (a level of detail of entity) show only while the camera is between near and far units from entity; far 0 means no upper limit.
CameraExposure: (ext) Sets the exposure of camera: mode 0 uses the fixed exposure (default 1), 1 adjusts it automatically between min_luminance and max_luminance, as eyes adjust between dark and bright places.
CameraColorGrading: (ext) Applies a colour grading table to camera, from a 256x16 image file; an empty file name removes it.
CameraToTexture: (ext) Makes camera render into texture instead of the screen; texture 0 renders to the screen again.

# Shaders
LoadShader: (ext) Loads a shader and compiles it: a GLSL file (.glsl), a WGSL file (.wgsl), a Fyrox shader file (.shader), or a built-in shader named "builtin:<name>" (unlit, textured, diffuse, phong, blinnphong, pbr, toon, water, hologram, ... see docs/SHADERS.md). Returns the shader; ShaderError tells why one failed to compile. Returns 0 only if the file cannot be read.
CreateShader: (ext) Creates a shader from source text in language "glsl" (default), "wgsl" or "fyrox" and returns it. It is compiled by CompileShader, or when first used.
CompileShader: (ext) Compiles shader and returns 1 on success. On failure it returns 0, ShaderError holds the file, line and message, and the last version that compiled stays in use.
ReloadShader: (ext) Reads shader's file again and compiles it; returns 1 on success.
FreeShader: (ext) Frees shader; entities drawn with it go back to their normal materials.
ValidateShader: (ext) Checks shader's current source (including a GPU compile once the window is open) without using it; returns 1 if it is valid, otherwise 0 and ShaderError says why.
ShaderValidate: (ext) Same as ValidateShader.
ShaderExists: (ext) Returns 1 if shader is a shader that exists.
ShaderCompiled: (ext) Returns 1 if the last compile of shader succeeded.
ShaderError: (ext) Returns the error of shader's last compile or validation, with file and line (empty if there was none).
ShaderCompileError: (ext) Same as ShaderError.
ShaderLog: (ext) Returns shader's log: each compile, warning, error and hot reload, one per line.
ShaderSource: (ext) Replaces the whole source of shader with source; compile it again with CompileShader.
ShaderVertexSource: (ext) Sets the vertex stage of shader to source (the text after //! vertex); compile it again with CompileShader.
ShaderFragmentSource: (ext) Sets the fragment stage of shader to source (the text after //! fragment); compile it again with CompileShader.
ShaderGeometrySource: (ext) Always fails with an explanation: Fyrox's OpenGL 3.3 renderer has no geometry stage. Make geometry with the mesh commands or displace vertices in a vertex shader.
ShaderComputeSource: (ext) Always fails with an explanation: Fyrox's renderer has no compute stage. Compute into a texture with a post-processing effect and PostProcessOutput, or on the CPU.
ShaderGetSource: (ext) Returns shader's source: stage 0 the source as written, 1 the generated vertex program, 2 the generated fragment program, 3 the Fyrox shader text.
ShaderApply: (ext) Draws entity with shader (0 = back to its normal materials).
EntityShader: (ext) Draws entity with shader (0 = back to its normal materials). Same as ShaderApply with the arguments the other way round.
EntityMaterial: (ext) Draws entity with material (a shader or a material from CreatePBRMaterial, CreateToonMaterial, ...); 0 goes back to the normal materials.
ShaderEnable: (ext) Turns shader back on after ShaderDisable.
ShaderDisable: (ext) Turns shader off: its entities are drawn with their normal materials until ShaderEnable.
ShaderClone: (ext) Returns a copy of shader with its own parameters (it shares the compiled program).
ShaderSave: (ext) Saves shader to file: a .shader or .ron file gets the Fyrox shader, anything else the source. Returns 1 on success.
ShaderHotReload: (ext) With enable 1 (default), shader is compiled again whenever its file or a file it includes changes; a broken edit keeps the previous version and is reported in ShaderError.
ShaderSetKeyword: (ext) Turns keyword on (enable 1) or off (0) in shader: it becomes #define keyword in the source, and a //! directive can depend on it. Each set of keywords is compiled once and reused.
ShaderFloat: (ext) Sets the float parameter called name to value for entity only (other entities with the same shader keep the shader's value).
ShaderVector: (ext) Sets the vector parameter called name to x, y, z, w for entity only.
ShaderTexture: (ext) Sets the texture parameter called name to texture for entity only.

# Shader parameters
ShaderSetParameter: (ext) Sets the parameter called name of shader from text: numbers separated by commas or spaces ("1, 0.5, 0") or, for a texture parameter, a texture handle.
ShaderGetParameter: (ext) Returns the value of shader's parameter called name as text (numbers separated by commas, or a texture handle).
ShaderSetFloat: (ext) Sets the float parameter called name of shader to value.
ShaderSetInt: (ext) Sets the integer parameter called name of shader to value.
ShaderSetBool: (ext) Sets the bool parameter called name of shader to value (0 false, anything else true).
ShaderSetVector2: (ext) Sets the vec2 parameter called name of shader to x, y.
ShaderSetVector3: (ext) Sets the vec3 parameter called name of shader to x, y, z.
ShaderSetVector4: (ext) Sets the vec4 parameter called name of shader to x, y, z, w.
ShaderSetMatrix3: (ext) Sets the mat3 parameter called name of shader from 9 numbers in values, column by column.
ShaderSetMatrix4: (ext) Sets the mat4 parameter called name of shader from 16 numbers in values, column by column.
ShaderSetColor: (ext) Sets the colour parameter called name of shader from red, green, blue and alpha 0-255 (alpha default 255); shaders get them as 0-1.
ShaderSetTexture: (ext) Sets the texture parameter called name of shader to texture.
ShaderSetTextureArray: (ext) Stacks the textures listed in textures (handles separated by commas, all the same size) into one array texture for parameter name; read layer n in GLSL with nb_textureArray(name, uv, n).
ShaderSetCubeMap: (ext) Sets the samplerCube parameter called name of shader to a cube map texture (loaded with flag 128).
ShaderSetTime: (ext) Sets the nb_time value shader sees to time seconds; -1 (default) goes back to the running time.
ShaderSetResolution: (ext) Sets the nb_resolution value shader sees to width x height pixels; 0 (default) goes back to the window size.
ShaderSetCamera: (ext) Gives shader camera's position and matrices, in the parameters nb_cameraPosition, nb_viewMatrix, nb_projectionMatrix and nb_viewProjection it declares.
ShaderSetLight: (ext) Gives shader light's position, direction (towards the light), colour and range, in the parameters nb_lightPosition, nb_lightDirection, nb_lightColor and nb_lightRange it declares; for arrays, index picks the element.
ShaderSetMaterial: (ext) Copies into shader every parameter value of material that both declare, and returns how many were copied.
ShaderSetBuffer: (ext) Sets the array parameter called name of shader (float[n], vec4[n], ...) from the numbers in values.
ShaderParameterExists: (ext) Returns 1 if shader declares a parameter called name.
ShaderParameterCount: (ext) Returns the number of parameters shader declares (textures included).
ShaderParameterName: (ext) Returns the name of shader's parameter number index (0 to ShaderParameterCount - 1).
ShaderParameterType: (ext) Returns the type of shader's parameter called name: "float", "vec3", "mat4", "float[16]", "sampler2D", "samplerCube", ...

# Shader debugging
ShaderDebug: (ext) Returns a report on shader: language, backend, status, passes, parameters, bindings, attributes, files, keywords, resource use and the last error.
ShaderGetUniforms: (ext) Returns shader's uniform parameters as "name:type" separated by commas.
ShaderGetAttributes: (ext) Returns the vertex attributes shader reads as "name@location" separated by commas.
ShaderGetBindings: (ext) Returns shader's texture and uniform block bindings as "name:kind@binding" separated by commas.
ShaderGetResourceInfo: (ext) Returns shader's resource use: entities, materials, passes, parameters, keywords, compiles, last compile time, compiled shaders cached and cache hits.
ShaderGetCompilationStatus: (ext) Returns shader's state: SHADER_NOT_COMPILED, SHADER_COMPILED, SHADER_FAILED, or SHADER_VALIDATED (checked, waiting for the window to open for the GPU check).
ShaderGetBackend: (ext) Returns the rendering backend and shader languages, and for a shader its source language.

# Post-processing
CreatePostProcess: (ext) Creates a post-processing effect from source (GLSL with vec4 nb_post(vec2 uv), or WGSL) and returns it. Add it to a camera with AddPostProcess.
LoadPostProcess: (ext) Loads a post-processing effect from a file or "builtin:<name>" (bloom, exposure, tonemap, vignette, chromatic, grain, colorgrade, gamma, contrast, saturation, brightness, fxaa, outline, pixelate, crt, distortion, heathaze, blur, gaussian, radialblur, sharpen, dof, motionblur, ssr, ssao, fog, underwater, rain, snow, invert) and returns it, or 0 on failure.
AddPostProcess: (ext) Adds effect to the chain of camera (0 = every camera).
RemovePostProcess: (ext) Removes effect from the chain of camera (0 = from every chain); the effect still exists.
FreePostProcess: (ext) Removes effect from every chain and frees it.
SetPostProcess: (ext) Makes effect the only effect of camera; effect 0 clears camera's chain.
SetPostProcessParameter: (ext) Sets the parameter called name of effect from text (numbers separated by commas, or a texture handle).
SetPostProcessEnabled: (ext) Turns effect on (enable 1) or off (0) without removing it from its chains.
SetPostProcessOrder: (ext) Sets where effect runs in its chain: lower orders run first (effects start in the order they were made).
PostProcessInput: (ext) Chooses what effect reads: 0 (POST_PREVIOUS) the result so far, -1 (POST_ORIGINAL) the scene before any effect, or another effect's output.
PostProcessOutput: (ext) Makes effect draw into texture instead of the screen chain (render to texture); 0 draws to the chain again.
PostProcessResolution: (ext) Draws effect at scale (0.05 to 1) of the screen size, for cheaper blurs and glows.
PostProcessCamera: (ext) Makes effect run only for camera.
PostProcessPriority: (ext) A negative priority runs effect on the HDR image before tone mapping; 0 or more runs it on the final image.
PostProcessShader: (ext) Returns the shader of effect, for the ShaderSet* and Shader debugging commands.
SetUnderwaterEffect: (ext) Turns the underwater effect of camera on or off: tinted, wavy view with fog when the camera is below water_level; red, green, blue set the water colour.
SetRainEffect: (ext) Draws rain streaks over camera's view with amount 0-1 (0 turns it off) and speed.
SetSnowEffect: (ext) Draws falling snow over camera's view with amount 0-1 (0 turns it off) and speed.
SetAtmosphericFog: (ext) Adds height fog to camera from the depth buffer: density (0 turns it off), colour red, green, blue, and how fast it thins with height.

# Shadows
SetShadowMode: (ext) Sets real-time shadows: SHADOW_OFF, SHADOW_HARD or SHADOW_SOFT (filtered edges).
SetShadowQuality: (ext) Sets shadow map size and precision from quality 0 (512, half precision) to 3 (4096, full precision).
SetShadowResolution: (ext) Sets the shadow map size of directional and spot lights to size (64-8192); point lights use half.
SetShadowBias: (ext) Sets the shadow bias of every light (it moves shadows slightly to stop speckled "shadow acne"); new lights get it too.
SetShadowSoftness: (ext) Turns filtered soft shadow edges on (softness above 0) or off (0). Fyrox's soft shadows have a fixed filter size.
SetShadowDistance: (ext) Sets how far from the camera shadows are drawn, in world units.
SetShadowCascadeCount: (ext) Sets how many cascades (1 to 3) directional light shadows are split into; more cascades keep near shadows sharp.
EnableShadows: (ext) Turns real-time shadows on.
DisableShadows: (ext) Turns real-time shadows off.

# Toon and stylized materials
CreateToonMaterial: (ext) Creates a stylized material and returns it; mode is a shading mode (SHADING_TOON default, SHADING_CEL, SHADING_FLAT, SHADING_UNLIT, SHADING_VERTEXLIT, SHADING_PIXEL, SHADING_PS1, SHADING_MATCAP, SHADING_POSTERIZE, SHADING_HANDPAINTED, ...).
SetToonRamp: (ext) Lights material through a ramp texture: the light level picks a colour across it. Texture 0 goes back to steps.
SetLightingRamp: (ext) Same as SetToonRamp, for any ramp-lit material.
SetToonSteps: (ext) Sets how many flat bands of light material has (1 = two-tone).
SetToonOutline: (ext) Gives entities with material an outline of width units drawn around them (enable 1), or removes it (0).
SetOutlineColor: (ext) Sets the outline colour of material, red, green, blue and alpha 0-255.
SetOutlineWidth: (ext) Sets the outline width of material in units.
SetRimLighting: (ext) Turns rim lighting (a glow along the edges facing away from the camera) of material on or off; strength sets how bright it is.
SetRimColor: (ext) Sets the rim lighting colour of material, red, green, blue 0-255.
SetRimPower: (ext) Sets how thin the rim of material is: higher power gives a thinner rim.
SetShadingMode: (ext) Switches material to another shading mode (SHADING_TOON, SHADING_CEL, SHADING_FLAT, ...), keeping the parameters both modes have.
SetVertexLighting: (ext) Lights material per vertex (enable 1, the look of early 3D hardware) or goes back to toon shading (0).
SetFlatShading: (ext) Shades material with one flat colour per triangle (enable 1, low-poly look) or goes back to toon shading (0).
SetPixelShading: (ext) Draws material with crisp texture pixels and banded light (enable 1, pixel-art look) or goes back to toon shading (0).

# Water, wind and foliage
CreateWaterMaterial: (ext) Creates an animated water material and returns it: waves, depth colour, foam, reflections and refraction. Give the water mesh enough vertices for the waves.
SetWaterWaves: (ext) Sets the waves of material: height, length (units between crests) and the direction dir_x, dir_z they travel.
SetWaterSpeed: (ext) Sets how fast the waves of material move.
SetWaterDepth: (ext) Sets the depth in units at which material reaches its deep colour.
SetWaterReflection: (ext) Sets how much material reflects (0-1), optionally from cubemap.
SetWaterRefraction: (ext) Sets how much material bends the view of what is under the water.
SetWaterFoam: (ext) Sets how much foam material shows near shores and on crests, and its colour red, green, blue.
SetWaterColor: (ext) Sets the shallow and deep colours of water material, 0-255.
SetWindDirection: (ext) Sets the direction x, z of the global wind, used by foliage and wind materials.
SetWindStrength: (ext) Sets the strength of the global wind.
CreateFoliageMaterial: (ext) Creates a material for leaves and grass that sways in the wind and returns it; tips (higher vertices) move more than roots.
SetFoliageWind: (ext) Gives foliage material its own wind strength, speed and stiffness instead of the global wind.

# Procedural materials
CreateProceduralShader: (ext) Creates a procedural material and returns it: kind 0 a gradient, 1 noise, 2 a pattern. Mix them with the commands below.
SetGradient: (ext) Sets the gradient of material: GRADIENT_LINEAR, GRADIENT_RADIAL, GRADIENT_ANGULAR or GRADIENT_NONE.
SetGradientColor: (ext) Sets gradient colour index (0 start, 1 end) of material, red, green, blue, alpha 0-255.
SetGradientDirection: (ext) Sets the angle of a linear gradient (or the start of an angular one) in degrees.
SetNoiseType: (ext) Sets the noise of material: NOISE_VALUE, NOISE_PERLIN, NOISE_SIMPLEX, NOISE_VORONOI or NOISE_CELLULAR.
SetNoiseScale: (ext) Sets the size of noise features of material (higher = smaller features).
SetNoiseSpeed: (ext) Sets how fast the noise of material moves (0 = still).
SetNoiseOctaves: (ext) Sets how many layers of finer noise (fractal Brownian motion, 1-12) material adds together.
SetNoisePersistence: (ext) Sets how strong each finer noise layer of material is compared with the one before (usually 0.5).
SetNoiseLacunarity: (ext) Sets how much finer each noise layer of material is than the one before (usually 2).
SetNoiseStrength: (ext) Sets how much the noise of material disturbs its gradient.
SetPattern: (ext) Sets the pattern of material: PATTERN_NONE, PATTERN_CHECKER, PATTERN_GRID, PATTERN_STRIPES, PATTERN_DOTS, PATTERN_CELLS or PATTERN_NOISE.
SetPatternScale: (ext) Sets how many times the pattern of material repeats across it.
SetPatternColor: (ext) Sets the pattern colour of material, red, green, blue, alpha 0-255 (alpha sets how strongly it covers the gradient).
SetPatternRotation: (ext) Rotates the pattern of material by angle degrees.
SetDistortion: (ext) Warps material's gradient and pattern with its noise by amount.
SetProceduralSeed: (ext) Sets the seed of material, giving a different variation of its noise and cells.
BakeProceduralTexture: (ext) Draws procedural material into a new texture of width x height and returns it, so it can be used as any texture (with normal_map 1 it makes a normal map from its noise instead).

# Loading and saving scenes
SaveScene: (ext) Saves every top-level entity as a Fyrox scene file (.rgs) that LoadMesh can load back as one entity; cameras, collision, pick and physics settings and sounds are not saved. Returns 1 on success.
SaveEntity: (ext) Saves entity and its children as a Fyrox scene file (.rgs) named file, to be loaded back with LoadMesh. Returns 1 on success.
ReloadAssets: (ext) Reads every loaded texture, image, sound and model again from its file, keeping each handle's settings (scale, frames, handle, volume, ...) and the entities using them; returns how many were reloaded. Useful after changing art while the game runs.
WatchAssets: (ext) With enable 1, checks the files of loaded textures, images, sounds and models about once a second and reloads the ones that changed on disk, so art edited in another program shows up while the game runs; 0 stops watching.
AssetsReloaded: (ext) Returns how many assets were reloaded (by ReloadAssets or WatchAssets) since the last call.
ModelName: (ext) Returns the file entity's model was loaded from, or "" if it is not a loaded model.
LoadPrefab: (ext) Loads a model or saved scene file (from SaveScene or SaveEntity, the Fyrox editor, glTF or FBX) once as a prefab and returns its handle, or 0 if it cannot be loaded. Place it with InstancePrefab.
CreatePrefab: (ext) Makes entity (built in the program, with its children) a prefab and returns its handle. The entity is hidden and kept as the original that InstancePrefab copies.
EntityBatch: (ext) Draws the children of mesh entity (one made with CreateMesh) merged into a few batches, one per material, instead of one by one: much faster for forests, rocks and other scenery made of many copies. Mode 1 bakes them where they are now (call again after adding or moving children), 2 merges them every frame so they can move, 0 turns batching off. A batch is drawn in one pass: if any child needs the forward pass (EntityFX, blending), all of them are drawn with the fixed-function-style material, so keep such children in a batch of their own to keep PBR lighting and received shadows on the rest.
InstancePrefab: (ext) Places a new copy of prefab and returns the new entity (parent optional). Copies of a file prefab share its meshes, materials and textures, and ReloadAssets updates them all.
PrefabName: (ext) Returns the file prefab was loaded from, or the name of its original entity.
EntityPrefab: (ext) Returns the prefab entity was placed from with InstancePrefab, or 0.
FreePrefab: (ext) Frees prefab (and the original entity of a CreatePrefab prefab); copies already placed stay.
CreateScene: (ext) Creates a new empty scene and returns its handle (scene 1 is the one Graphics3D makes). Each scene has its own entities, lights, ambient light, physics and sounds; its cameras draw with a see-through background over the scenes made before it. Use SetScene to build in it.
SetScene: (ext) Makes scene the current scene: new entities go into it and commands work on its entities (using an entity of another scene is an error, so read what you need before switching).
CurrentScene: (ext) Returns the current scene.
ShowScene: (ext) Shows scene again after HideScene: it is drawn and updated.
HideScene: (ext) Hides scene: it is not drawn, UpdateWorld does not move it and its physics stops, but everything in it is kept (a paused level, an interior, a menu).
SceneVisible: (ext) Returns 1 if scene is shown, 0 if hidden.
FreeScene: (ext) Frees scene and every entity in it (scene 1 cannot be freed). If it was current, scene 1 becomes current.
EntityScene: (ext) Returns the scene entity is in.

# GUI widgets
GuiWindow: (ext) Creates a window with title at x,y of size width by height (draggable, with a close button) and returns its handle; widgets created with it as parent are stacked inside. GuiValue is 1 while it is open; closing it sets 0 and counts as a change. SetGuiValue window, 1 or 0 opens or closes it.
GuiPanel: (ext) Creates a panel that lays out the widgets put in it: layout 0 in a column, 1 in a row, 2 wrapping into rows, 3 free (place them with SetGuiPosition); returns its handle.
GuiGrid: (ext) Creates a grid of columns by rows equal cells and returns its handle; put widgets in it and choose their cell with GuiCell.
GuiCell: (ext) Puts widget in cell column, row of the grid it is in (counting from 0).
GuiScroll: (ext) Creates a scrolling area; widgets put in it are stacked in a column and scroll when they do not fit. Returns its handle.
GuiButton: (ext) Creates a button showing text and returns its handle; GuiClicked tells when it was pressed.
GuiLabel: (ext) Creates a line of text and returns its handle; change it with SetGuiText.
GuiTextBox: (ext) Creates a box the user can type in, starting with text, and returns its handle; multiline 1 allows several lines. GuiText reads what was typed and GuiChanged counts edits.
GuiCheckBox: (ext) Creates a check box labelled text, ticked if checked is 1, and returns its handle; GuiValue is 1 when ticked and GuiChanged counts changes.
GuiSlider: (ext) Creates a slider from min to max starting at value and returns its handle; GuiValue reads it and GuiChanged counts moves.
GuiProgress: (ext) Creates a progress bar showing value (0 to 1) and returns its handle; change it with SetGuiValue.
GuiImage: (ext) Creates a widget showing image (from LoadImage or CreateImage) and returns its handle. With GuiClicked and GuiMouseX/GuiMouseY it can be used as a custom widget the program draws itself.
SetGuiText: (ext) Changes the text of widget (button, label, text box, check box, window title and the text of list, tree, tab and menu items).
GuiText: (ext) Returns the text of widget: what was typed in a text box, the selected item of a list or drop-down, or the widget's label.
SetGuiValue: (ext) Sets the value of widget: a slider's position, a progress bar (0 to 1), a check box (1 ticked, 0 not), a number box, or a window (1 open, 0 closed).
GuiValue: (ext) Returns the value of widget (slider, progress, check box, number box, window open state, message box answer, selected index).
GuiClicked: (ext) Returns how many times widget was clicked since the last call (0 if not), like KeyHit.
GuiChanged: (ext) Returns how many times the user changed widget since the last call (typed, ticked, moved, selected, closed or answered), like KeyHit.
SetGuiPosition: (ext) Moves widget to x,y (logical pixels) inside the screen or a free panel.
SetGuiSize: (ext) Sets widget's width and height in logical pixels; 0 makes that side as big as the content needs.
GuiMargin: (ext) Sets the space around widget: left, top, right and bottom in pixels.
GuiAlign: (ext) Aligns widget inside the space its container gives it: horizontal and vertical are 0 stretch, 1 left/top, 2 centre, 3 right/bottom.
GuiVisible: (ext) Shows (1) or hides (0) widget and everything in it.
GuiEnable: (ext) Enables (1) or disables (0) widget; a disabled widget is greyed out and ignores the user.
GuiFocus: (ext) Gives widget the keyboard focus (a text box can then be typed in at once).
GuiTooltip: (ext) Shows text in a small box when the mouse rests on widget.
GuiColor: (ext) Sets the background colour of widget (red, green, blue, alpha 0-255); buttons get lighter and darker shades for hover and press.
GuiTextColor: (ext) Sets the text colour of widget (red, green, blue 0-255).
GuiFontSize: (ext) Sets the size of the text in widget, in pixels.
FreeGui: (ext) Removes widget and everything in it.
GuiMouseX: (ext) Returns the mouse's x position relative to widget's left edge, in logical pixels.
GuiMouseY: (ext) Returns the mouse's y position relative to widget's top edge, in logical pixels.
GuiUnderMouse: (ext) Returns 1 if the mouse is over a GUI widget, so a game can ignore clicks meant for the GUI.
GuiTheme: (ext) Styles every GUI widget with the built-in dark (0) or light (1) theme.
GuiThemeColor: (ext) Changes one colour of the GUI theme for every widget: name is a theme brush such as Primary, Dark, Light, Text, Foreground, Highlight or BrightBlue (red, green, blue, alpha 0-255).
GuiThemeFontSize: (ext) Sets the text size of every GUI widget, in pixels.
GuiDropDown: (ext) Creates a drop-down list from items separated by "|" (e.g. "Low|Medium|High") in parent (0 = the screen) and returns its handle; the first item starts selected, and when the player picks one, GuiSelected/GuiValue give its index, GuiText its text and GuiChanged reports the change.
GuiList: (ext) Creates a list box showing items separated by "|" in parent (0 = the screen) and returns its handle; nothing starts selected, and a click selects an item: GuiSelected/GuiValue give its index, GuiText its text and GuiChanged reports the change.
GuiAddItem: (ext) Adds an item with the given text to the end of a drop-down or list.
GuiRemoveItem: (ext) Removes the item at index (0 = first) from a drop-down or list; if it was selected, nothing is selected afterwards.
GuiClearItems: (ext) Removes every item from a drop-down or list and clears the selection.
GuiCountItems: (ext) Returns how many items a widget has: entries of a drop-down or list, tabs of a tab control, top-level items of a tree or menu bar, or children of a tree or menu item.
GuiItemText: (ext) Returns the text of the item at index (0 = first) of a drop-down, list, tab control, tree, menu or menu item.
GuiSelected: (ext) Returns the selected item: an index (0 = first, -1 = none) for a drop-down, list or tab control (the active tab), or the handle of the selected tree item for a tree (0 = none).
SetGuiSelected: (ext) Selects an item from the program: an index for a drop-down, list or tab control (-1 clears a drop-down or list), or a tree item's handle for a tree (0 clears); this does not count as a change for GuiChanged.
GuiTree: (ext) Creates an empty tree view in parent (0 = the screen) and returns its handle; fill it with GuiTreeItem, and read the clicked item with GuiSelected (GuiText gives its text, GuiChanged reports a new selection).
GuiTreeItem: (ext) Adds an item with the given text to a tree, or under another tree item when parent is a tree item, and returns the item's own handle; GuiClicked(item) counts how often it was selected, and SetGuiText renames it.
GuiExpand: (ext) Opens (expand = 1) or closes (expand = 0) a tree item so its children are shown or hidden.
GuiTabs: (ext) Creates an empty tab control in parent (0 = the screen) and returns its handle; add pages with GuiTab, and read the active tab with GuiSelected/GuiValue (0 = first) and GuiChanged.
GuiTab: (ext) Adds a page with the given title to a tab control and returns the page's handle, which can be used as the parent of other widgets (they are stacked in a column); the first page added becomes active, and SetGuiText changes the title.
GuiMenu: (ext) Creates an empty menu bar in parent (0 = the screen) and returns its handle; add its menus with GuiMenuItem.
GuiMenuItem: (ext) Adds an item with the given text to a menu bar, or to the sub-menu of another menu item when parent is a menu item, and returns the item's handle; GuiClicked(item) returns how many times it was chosen since last asked, and SetGuiText renames it.
GuiBorder: (ext) Creates a box with a border line (thickness in pixels, default 1) that holds other widgets stacked in a column; parent is the widget to put it in (0 = the screen). Returns the border's handle, which you pass as the parent of the widgets that go inside.
GuiPopup: (ext) Creates a hidden popup of the given width and height (0 = as big as its contents) that holds other widgets stacked in a column. Open it with GuiShowPopup; it closes when the user clicks outside it or presses Escape. GuiValue is 1 while open and 0 when closed, and GuiChanged counts the times the user closed it. Returns the popup's handle.
GuiShowPopup: (ext) Opens a popup at the mouse position (show = 1) or closes it (show = 0).
GuiMessageBox: (ext) Shows a message box with a title and text in the middle of the screen at once and blocks clicks on the rest of the GUI until it is answered. buttons: 0 OK, 1 Yes/No, 2 Yes/No/Cancel. When the user answers, GuiChanged becomes non-zero and GuiValue is 1 for OK/Yes, 2 for No, 3 for Cancel. Returns the message box's handle.
GuiFileBrowser: (ext) Creates a folder tree that starts at path ("" = the current folder), 300 by 250 pixels; parent is the widget to put it in (0 = the screen). When the user picks a file or folder, GuiChanged becomes non-zero and GuiText returns its path. Returns the browser's handle.
GuiFileDialog: (ext) Opens a file dialog window in the middle of the screen at once, with a title and a starting path (a folder, or a file whose name is filled in). save = 1 makes it a Save dialog. When the user clicks Open/Save, GuiChanged becomes non-zero, GuiValue is 1 and GuiText is the chosen path; when the user clicks Cancel, GuiChanged becomes non-zero and GuiValue is 0. Returns the dialog's handle.
GuiDock: (ext) Creates a docking area, 400 by 300 pixels (resize it with SetGuiSize), where GuiWindows can be docked side by side or as tabs and dragged in and out by the user; parent is the widget to put it in (0 = the screen). Returns the dock's handle.
GuiDockWindow: (ext) Puts a GuiWindow into a dock. place: 0 leaves it floating so the user can drag it onto the dock, 1 docks it on the left, 2 right, 3 top, 4 bottom, 5 as a tab in the middle.
GuiModal: (ext) Opens a GuiWindow in the middle of the screen as a modal window: the rest of the GUI ignores clicks until the window is closed.
GuiCenter: (ext) Moves a widget to the middle of the widget it is in (the screen for widgets with parent 0).
GuiNumber: (ext) Creates a number box with up/down arrows (you can also type in it or drag the arrows) showing value, kept between min and max and changed by step per click; returns the widget handle. Read it with GuiValue, set it with SetGuiValue, and GuiChanged tells you when the user edits it.
GuiVector3: (ext) Creates an editor with three number boxes for an X, Y, Z vector, starting at x, y, z; returns the widget handle. Read the parts with GuiVectorValue, set them with SetGuiVector; GuiChanged tells you when the user edits it.
GuiColorPicker: (ext) Creates a full colour picker (colour square, hue and alpha bars, RGB/HSV boxes) starting at the colour red, green, blue (0-255, default white); returns the widget handle. Read the colour with GuiVectorValue (0 red, 1 green, 2 blue, 3 alpha), set it with SetGuiVector; GuiChanged tells you when the user picks a colour.
GuiColorField: (ext) Creates a small colour swatch showing red, green, blue (0-255) that opens a colour picker when clicked; returns the widget handle. The new colour arrives when the picker closes: read it with GuiVectorValue (0 red, 1 green, 2 blue, 3 alpha), set it with SetGuiVector; GuiChanged tells you when it changes.
GuiVectorValue: (ext) Returns one part of a vector editor or colour widget as a float: component 0, 1, 2 are x, y, z of a GuiVector3, or 0-3 are red, green, blue, alpha (0-255) of a GuiColorPicker or GuiColorField.
SetGuiVector: (ext) Sets a GuiVector3 to x, y, z, or a GuiColorPicker or GuiColorField to the colour x=red, y=green, z=blue, w=alpha (0-255, 255 if left out). Does not count as a change for GuiChanged.
GuiCurve: (ext) Creates a curve editor showing a curve that starts as a straight line from (0,0) to (1,1); the user can drag, add and remove keys (right-click for the menu). Returns the widget handle; GuiChanged tells you when the user edits the curve.
GuiCurveKey: (ext) Adds a key (point) at position x with value y to a GuiCurve; the curve is a straight line between keys.
GuiClearCurve: (ext) Removes every key from a GuiCurve, leaving it empty (an empty curve has the value 0 everywhere).
GuiCurveValue: (ext) Returns the value of a GuiCurve at position x, following the curve as currently edited by the user; before the first key it is the first key's value and after the last key the last key's value.
