# Command reference

Every NeptuneBASIC command, grouped by area. Generated by `python tools/gen_reference.py` from the command tables and [commands.txt](commands.txt); edit that file, not this one.

**Reading the entries:** a command that returns a value is shown as a function call, `Name(a, b)`, with the type it returns. Other commands are statements, `Name a, b`. Parameter types use Blitz tags: `%` integer, `#` float, `$` string. Optional parameters are in brackets with their default value. **(ext)** marks extensions that Blitz3D did not have; everything else works like Blitz3D. Language keywords and built-in functions (`If`, `Type`, `Abs`, `Int`, `Str`, `Handle`, ...) are described in [LANGUAGE.md](LANGUAGE.md).

721 commands and 59 modern names.

## Program and system

### RuntimeError

`RuntimeError message$`

Stops the program with a runtime error showing message.

### CommandLine

`CommandLine()` → string

Returns the arguments passed to the program after the source or program name, joined by spaces.

### GetEnv

`GetEnv(name$)` → string

Returns the value of the environment variable name, or an empty string if it is not set.

### SetEnv

`SetEnv name$, value$`

Sets the environment variable name to value for this program and any programs it starts.

### SystemProperty

`SystemProperty(property$)` → string

Returns a system property as a string: "appdir", "tempdir", "currentdir", "homedir", "windowsdir" and "systemdir" give folders ending in a path separator, "os" the operating system name and "cpucount" the number of CPU cores. Unknown properties return an empty string.

### ExecFile

`ExecFile file$`

Opens file with the program the operating system associates with it (a document, web address or program); does not wait for it to finish.

## Console input and output

### Print

`Print [value=""]`

Writes value (any type, default an empty string) to the console followed by a new line.

### Write

`Write value`

Writes value (any type) to the console without a new line.

### Input

`Input([prompt$=""])` → string

Shows prompt on the console, waits for the user to type a line and returns it as a string without the line ending.

### DebugLog

`DebugLog message$`

Writes message to the debug log (standard error), followed by a new line.

## Networking

### OpenTCPStream

`OpenTCPStream(server$, port%)` → integer

Connects to server (a host name or IP address) on port and returns a TCP stream handle, or 0 if the connection fails. Use the stream commands to send and receive.

### CloseTCPStream

`CloseTCPStream stream%`

Closes the TCP stream.

### CreateTCPServer

`CreateTCPServer(port%)` → integer

Starts a TCP server listening on port and returns its handle, or 0 on failure.

### CloseTCPServer

`CloseTCPServer server%`

Stops the TCP server.

### AcceptTCPStream

`AcceptTCPStream(server%)` → integer

Returns a stream for the next client that has connected to server, or 0 if none is waiting.

### TCPStreamIP

`TCPStreamIP(stream%)` → integer

Returns the integer IP address of the other end of the TCP stream; use DottedIP to show it.

### TCPStreamPort

`TCPStreamPort(stream%)` → integer

Returns the port of the other end of the TCP stream.

### TCPTimeouts

`TCPTimeouts read_millis%, accept_millis%`

Sets how long TCP reads wait for data (read_millis) and how long AcceptTCPStream waits for a client (accept_millis), in milliseconds.

### CreateUDPStream

`CreateUDPStream([port%=0])` → integer

Opens a UDP stream on port (0 picks a free port) and returns its handle, or 0 on failure.

### CloseUDPStream

`CloseUDPStream stream%`

### SendUDPMsg

`SendUDPMsg stream%, dest_ip%, [dest_port%=0]`

Sends the data written to the UDP stream as one message to the integer IP address dest_ip and dest_port (0 uses the stream's own port).

### RecvUDPMsg

`RecvUDPMsg(stream%)` → integer

Receives the next UDP message on stream so it can be read with the stream commands, and returns the sender's integer IP address, or 0 if there is none.

### UDPStreamIP

### UDPStreamPort

`UDPStreamPort(stream%)` → integer

### UDPMsgIP

### UDPMsgPort

`UDPMsgPort(stream%)` → integer

### UDPTimeouts

`UDPTimeouts recv_millis%`

Sets how long RecvUDPMsg waits for a message, in milliseconds (recv_millis).

## Multiplayer games

### StartNetGame

`StartNetGame()` → integer

Joins a game found on the local network, or hosts a new one if there is none. Returns 1 if it joined, 2 if it is hosting, or 0 on failure. Uses TCP instead of Blitz3D's DirectPlay dialog.

### HostNetGame

`HostNetGame(game_name$)` → integer

Hosts a multiplayer game called game_name that others can join, and returns 2 on success or 0 on failure.

### JoinNetGame

`JoinNetGame(game_name$, server_ip$)` → integer

Joins the game game_name at server_ip (an empty address searches the local network) and returns 1 on success or 0 on failure.

### StopNetGame

`StopNetGame`

Leaves or stops the current multiplayer game.

### CreateNetPlayer

`CreateNetPlayer(name$)` → integer

Creates a local player called name in the current game and returns its player id.

### DeleteNetPlayer

`DeleteNetPlayer player%`

Removes the local player from the game.

### NetPlayerName

`NetPlayerName(player%)` → string

Returns the name of player.

### NetPlayerLocal

`NetPlayerLocal(player%)` → integer

Returns true if player was created on this computer.

### SendNetMsg

`SendNetMsg(type%, data$, from_player%, [to_player%=0], [reliable%=1])` → integer

Sends a message of type (1-99) with the text data from from_player to to_player (0 sends to all players). Returns true on success; messages are always sent reliably.

### RecvNetMsg

`RecvNetMsg()` → integer

Fetches the next received message and returns true, or false if there is none; read it with NetMsgType, NetMsgFrom, NetMsgTo and NetMsgData.

### NetMsgType

`NetMsgType()` → integer

Returns the type of the last received message: 1-99 for player messages, 100 for a player joining, 101 for a player leaving and 200 when the session is lost.

### NetMsgFrom

`NetMsgFrom()` → integer

Returns the player id that sent the last received message (for type 100, the new player).

### NetMsgTo

`NetMsgTo()` → integer

Returns the player id the last received message was sent to, or 0 if it was sent to everyone.

### NetMsgData

`NetMsgData()` → string

Returns the text of the last received message.

### DottedIP

`DottedIP(ip%)` → string

Returns the integer IP address ip as a dotted string such as "192.168.0.1".

### CountHostIPs

`CountHostIPs(host_name$)` → integer

Looks up the IP addresses of host_name (an empty string for this computer) and returns how many were found.

### HostIP

`HostIP(index%)` → integer

Returns address number index (from 1) found by the last CountHostIPs, as an integer IP address.

## Plugins and libraries

## Gamma and quality

### GraphicsQuality

`GraphicsQuality level%`

**(ext)** Sets the renderer quality preset: level 0 low, 1 medium, 2 high, 3 ultra (QUALITY_LOW to QUALITY_ULTRA). Use a low level for old graphics cards.

### GetGraphicsQuality

`GetGraphicsQuality()` → integer

**(ext)** Returns the current quality level set with GraphicsQuality (0-3).

### PostEffect

`PostEffect effect%, [enable%=1]`

**(ext)** Turns a rendering effect on (enable = 1) or off (enable = 0): EFFECT_BLOOM, EFFECT_SSAO, EFFECT_FXAA, EFFECT_SHADOWS or EFFECT_LIGHT_SCATTER.

### AntiAlias

`AntiAlias enable%`

Turns anti-aliasing (smoothing of jagged edges) on or off.

### SetGamma

`SetGamma src_red%, src_green%, src_blue%, dest_red#, dest_green#, dest_blue#`

Sets the gamma ramp so that the colour levels src_red, src_green, src_blue (0-255) are shown as dest_red, dest_green, dest_blue. Call UpdateGamma to apply it.

### UpdateGamma

`UpdateGamma [calibrate%=0]`

Applies the gamma changes made with SetGamma; calibrate is accepted for compatibility.

### GammaRed

`GammaRed(red%)` → float

Returns the output level the red level red (0-255) is mapped to by the gamma ramp.

### GammaGreen

`GammaGreen(green%)` → float

Returns the output level the green level green (0-255) is mapped to by the gamma ramp.

### GammaBlue

`GammaBlue(blue%)` → float

Returns the output level the blue level blue (0-255) is mapped to by the gamma ramp.

## Models and animation

### CaptureWorld

`CaptureWorld`

Records the position, rotation and scale of every entity, for RenderWorld tweening.

### AddAnimSeq

`AddAnimSeq(entity%, length%)` → integer

Adds an empty keyframe animation sequence of length frames to entity and returns its number; fill it with SetAnimKey.

### SetAnimKey

`SetAnimKey entity%, frame%, [pos_key%=1], [rot_key%=1], [scale_key%=1]`

Stores entity's current position, rotation and/or scale (chosen by pos_key, rot_key, scale_key) as a key at frame of its last added sequence.

### LoaderMatrix

`LoaderMatrix file_extension$, xx#, xy#, xz#, yx#, yy#, yz#, zx#, zy#, zz#`

Sets the matrix applied to models loaded from files with file_extension; the three rows xx,xy,xz / yx,yy,yz / zx,zy,zz are the new X, Y and Z axes.

### LoadAnimSeq

`LoadAnimSeq(entity%, file$)` → integer

Loads the animations from another model file and adds them to the animated model entity (retargeted to its skeleton); returns the number of the first new sequence, or -1 on failure.

### LoadMesh

`LoadMesh(file$, [parent%=0])` → integer

Loads a glTF (.gltf/.glb), FBX or saved scene file as a single entity and returns its handle, or 0 on failure; parent is optional. Old Blitz formats (.b3d, .x, .3ds) are not supported.

### LoadMeshAsync

`LoadMeshAsync(file$, [parent%=0])` → integer

**(ext)** Starts loading a model file in the background and returns its entity at once; the model appears in it when loaded. parent is optional.

### EntityLoaded

`EntityLoaded(entity%)` → integer

**(ext)** Returns 1 if the model of entity has finished loading (always for other entities), 0 while it is still loading, -1 if loading failed.

### PendingLoads

`PendingLoads()` → integer

**(ext)** Returns the number of background model and texture loads still in progress.

### LoadAnimMesh

`LoadAnimMesh(file$, [parent%=0])` → integer

Loads an animated model (with its bone hierarchy and animations) from file and returns it as an entity, optionally attached to parent. Returns 0 if the file cannot be loaded.

### Animate

`Animate entity%, [mode%=1], [speed#=1], [sequence%=0], [transition#=0]`

Starts animating entity: mode 0 stops, 1 loops, 2 ping-pongs, 3 plays once; speed scales playback, sequence picks the animation sequence and transition is the number of frames to blend from the current pose.

### SetAnimTime

`SetAnimTime entity%, time#, [sequence%=0]`

Jumps entity's animation to time (in frames) in the given sequence.

### Animating

`Animating(entity%)` → integer

Returns 1 if entity is currently animating, otherwise 0.

### AnimTime

### AnimSeq

### AnimLength

### ExtractAnimSeq

### CountAnimSeqs

**(ext)** Returns how many animation sequences entity has (0 if it is not animated).

### CreateBallJoint

### JointLimits

### RagdollImpulse

### EmitterEnable

### EmitterClear
