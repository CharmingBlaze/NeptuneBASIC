# Command reference

Every NeptuneBASIC command, grouped by area. Generated by `python tools/gen_reference.py` from the command tables and [commands.txt](commands.txt); edit that file, not this one.

**Reading the entries:** a command that returns a value is shown as a function call, `Name(a, b)`, with the type it returns. Other commands are statements, `Name a, b`. Parameter types use Blitz tags: `%` integer, `#` float, `$` string. Optional parameters are in brackets with their default value. **(ext)** marks extensions that Blitz3D did not have; everything else works like Blitz3D. Language keywords and built-in functions (`If`, `Type`, `Abs`, `Int`, `Str`, `Handle`, ...) are described in [LANGUAGE.md](LANGUAGE.md).

1040 commands and 60 modern names.

## Program and system

### RuntimeError

`RuntimeError message$`

Stops the program with a runtime error showing message.

### CommandLine

`CommandLine()` → string

Returns the arguments passed to the program after the source or program name, joined by spaces.

### GetEnv

`GetEnv(name$)` → string

Returns the value of the environment variable name, or an empty string if it is not set.

### SetEnv

`SetEnv name$, value$`

Sets the environment variable name to value for this program and any programs it starts.

### SystemProperty

`SystemProperty(property$)` → string

Returns a system property as a string: "appdir", "tempdir", "currentdir", "homedir", "windowsdir" and "systemdir" give folders ending in a path separator, "os" the operating system name and "cpucount" the number of CPU cores. Unknown properties return an empty string.

### ExecFile

`ExecFile file$`

Opens file with the program the operating system associates with it (a document, web address or program); does not wait for it to finish.

## Console input and output

### Print

`Print [value=""]`

Writes value (any type, default an empty string) to the console followed by a new line.

### Write

`Write value`

Writes value (any type) to the console without a new line.

### Input

`Input([prompt$=""])` → string

Shows prompt on the console, waits for the user to type a line and returns it as a string without the line ending.

### DebugLog

`DebugLog message$`

Writes message to the debug log (standard error), followed by a new line.

## Random numbers

### SeedRnd

`SeedRnd seed%`

Seeds the random number generator with seed so the same sequence of numbers is produced each run; MilliSecs() is a common seed.

### Rnd

`Rnd(from#, [to#=0])` → float

Returns a random float between from and to; with only one parameter it returns a float between 0 and from.

### Rand

`Rand(from%, [to%=1])` → integer

Returns a random integer between from and to inclusive; with only one parameter it returns an integer between 1 and from.

### RndSeed

`RndSeed()` → integer

Returns the seed last set with SeedRnd.

### CreateDir

## Streams

### ReadFile

`ReadFile(path$)` → integer

Opens the file at path for reading and returns a stream handle, or 0 if it cannot be opened.

### WriteFile

`WriteFile(path$)` → integer

Creates (or empties) the file at path for writing and returns a stream handle, or 0 on failure.

### OpenFile

`OpenFile(path$)` → integer

Opens an existing file at path for reading and writing and returns a stream handle, or 0 on failure.

### CloseFile

`CloseFile stream%`

Closes the file stream.

### Eof

`Eof(stream%)` → integer

Returns true once stream has no more data to read (for a TCP stream, when the connection has closed).

### ReadLine

`ReadLine(stream%)` → string

Reads a line of text from stream and returns it without the line ending.

### WriteLine

`WriteLine stream%, text$`

Writes text to stream followed by a line ending.

### ReadByte

`ReadByte(stream%)` → integer

Reads one byte (0-255) from stream and returns it.

### ReadShort

`ReadShort(stream%)` → integer

Reads a 2-byte unsigned integer (0-65535) from stream and returns it.

### ReadInt

`ReadInt(stream%)` → integer

Reads a 4-byte integer from stream and returns it.

### ReadFloat

`ReadFloat(stream%)` → float

Reads a 4-byte float from stream and returns it.

### ReadString

`ReadString(stream%)` → string

Reads a string stored as a 4-byte length followed by its characters (as written by WriteString) from stream.

### WriteByte

`WriteByte stream%, value%`

Writes value to stream as one byte.

### WriteShort

`WriteShort stream%, value%`

Writes value to stream as a 2-byte integer.

### WriteInt

`WriteInt stream%, value%`

Writes value to stream as a 4-byte integer.

### WriteFloat

`WriteFloat stream%, value#`

Writes value to stream as a 4-byte float.

### WriteString

`WriteString stream%, value$`

Writes value to stream as a 4-byte length followed by its characters.

### ReadAvail

`ReadAvail(stream%)` → integer

Returns how many bytes can be read from stream without waiting.

### FilePos

`FilePos(stream%)` → integer

Returns the current read/write position in the file stream, in bytes from the start.

### SeekFile

`SeekFile(stream%, pos%)` → integer

Moves the read/write position of the file stream to pos bytes from the start and returns the new position.

### CopyStream

`CopyStream src_stream%, dest_stream%, [buffer_size%=16384]`

Copies all remaining data from src_stream to dest_stream, buffer_size bytes at a time.

## Banks

### CreateBank

Creates a bank (a block of memory) of size bytes, filled with zeros, and returns its handle.

### FreeBank

`FreeBank bank%`

Deletes bank.

### BankSize

`BankSize(bank%)` → integer

Returns the size of bank in bytes.

### ResizeBank

`ResizeBank bank%, size%`

Changes the size of bank to size bytes, keeping its contents; new bytes are zero.

### CopyBank

`CopyBank src_bank%, src_offset%, dest_bank%, dest_offset%, count%`

Copies count bytes from src_bank at src_offset to dest_bank at dest_offset.

### PeekByte

### PeekShort

`PeekShort(bank%, offset%)` → integer

Returns the 2-byte unsigned integer at offset in bank.

### PeekInt

`PeekInt(bank%, offset%)` → integer

Returns the 4-byte integer at offset in bank.

### PeekFloat

`PeekFloat(bank%, offset%)` → float

Returns the 4-byte float at offset in bank.

### PokeByte

`PokeByte bank%, offset%, value%`

Writes value as one byte at offset in bank.

### PokeShort

`PokeShort bank%, offset%, value%`

Writes value as a 2-byte integer at offset in bank.

### PokeInt

`PokeInt bank%, offset%, value%`

Writes value as a 4-byte integer at offset in bank.

### PokeFloat

`PokeFloat bank%, offset%, value#`

Writes value as a 4-byte float at offset in bank.

### ReadBytes

`ReadBytes(bank%, stream%, offset%, count%)` → integer

Reads up to count bytes from stream into bank starting at offset and returns the number of bytes read.

### WriteBytes

`WriteBytes(bank%, stream%, offset%, count%)` → integer

## Networking

### OpenTCPStream

`OpenTCPStream(server$, port%)` → integer

Connects to server (a host name or IP address) on port and returns a TCP stream handle, or 0 if the connection fails. Use the stream commands to send and receive.

### CloseTCPStream

`CloseTCPStream stream%`

Closes the TCP stream.

### CreateTCPServer

`CreateTCPServer(port%)` → integer

Starts a TCP server listening on port and returns its handle, or 0 on failure.

### CloseTCPServer

`CloseTCPServer server%`

Stops the TCP server.

### AcceptTCPStream

`AcceptTCPStream(server%)` → integer

Returns a stream for the next client that has connected to server, or 0 if none is waiting.

### TCPStreamIP

`TCPStreamIP(stream%)` → integer

Returns the integer IP address of the other end of the TCP stream; use DottedIP to show it.

### TCPStreamPort

`TCPStreamPort(stream%)` → integer

Returns the port of the other end of the TCP stream.

### TCPTimeouts

`TCPTimeouts read_millis%, accept_millis%`

Sets how long TCP reads wait for data (read_millis) and how long AcceptTCPStream waits for a client (accept_millis), in milliseconds.

### CreateUDPStream

`CreateUDPStream([port%=0])` → integer

Opens a UDP stream on port (0 picks a free port) and returns its handle, or 0 on failure.

### CloseUDPStream

`CloseUDPStream stream%`

Closes the UDP stream.

### SendUDPMsg

`SendUDPMsg stream%, dest_ip%, [dest_port%=0]`

Sends the data written to the UDP stream as one message to the integer IP address dest_ip and dest_port (0 uses the stream's own port).

### RecvUDPMsg

`RecvUDPMsg(stream%)` → integer

Receives the next UDP message on stream so it can be read with the stream commands, and returns the sender's integer IP address, or 0 if there is none.

### UDPStreamIP

`UDPStreamIP(stream%)` → integer

Returns the local integer IP address of the UDP stream.

### UDPStreamPort

`UDPStreamPort(stream%)` → integer

Returns the local port of the UDP stream.

### UDPMsgIP

`UDPMsgIP(stream%)` → integer

Returns the integer IP address of the sender of the last message received on the UDP stream.

### UDPMsgPort

`UDPMsgPort(stream%)` → integer

Returns the port of the sender of the last message received on the UDP stream.

### UDPTimeouts

`UDPTimeouts recv_millis%`

Sets how long RecvUDPMsg waits for a message, in milliseconds (recv_millis).

## Multiplayer games

### StartNetGame

`StartNetGame()` → integer

Joins a game found on the local network, or hosts a new one if there is none. Returns 1 if it joined, 2 if it is hosting, or 0 on failure. Uses TCP instead of Blitz3D's DirectPlay dialog.

### HostNetGame

`HostNetGame(game_name$)` → integer

Hosts a multiplayer game called game_name that others can join, and returns 2 on success or 0 on failure.

### JoinNetGame

`JoinNetGame(game_name$, server_ip$)` → integer

Joins the game game_name at server_ip (an empty address searches the local network) and returns 1 on success or 0 on failure.

### StopNetGame

`StopNetGame`

Leaves or stops the current multiplayer game.

### CreateNetPlayer

`CreateNetPlayer(name$)` → integer

Creates a local player called name in the current game and returns its player id.

### DeleteNetPlayer

`DeleteNetPlayer player%`

Removes the local player from the game.

### NetPlayerName

`NetPlayerName(player%)` → string

Returns the name of player.

### NetPlayerLocal

`NetPlayerLocal(player%)` → integer

Returns true if player was created on this computer.

### SendNetMsg

`SendNetMsg(type%, data$, from_player%, [to_player%=0], [reliable%=1])` → integer

Sends a message of type (1-99) with the text data from from_player to to_player (0 sends to all players). Returns true on success; messages are always sent reliably.

### RecvNetMsg

`RecvNetMsg()` → integer

Fetches the next received message and returns true, or false if there is none; read it with NetMsgType, NetMsgFrom, NetMsgTo and NetMsgData.

### NetMsgType

`NetMsgType()` → integer

Returns the type of the last received message: 1-99 for player messages, 100 for a player joining, 101 for a player leaving and 200 when the session is lost.

### NetMsgFrom

`NetMsgFrom()` → integer

Returns the player id that sent the last received message (for type 100, the new player).

### NetMsgTo

`NetMsgTo()` → integer

Returns the player id the last received message was sent to, or 0 if it was sent to everyone.

### NetMsgData

`NetMsgData()` → string

Returns the text of the last received message.

### DottedIP

`DottedIP(ip%)` → string

Returns the integer IP address ip as a dotted string such as "192.168.0.1".

### CountHostIPs

`CountHostIPs(host_name$)` → integer

Looks up the IP addresses of host_name (an empty string for this computer) and returns how many were found.

### HostIP

`HostIP(index%)` → integer

Returns address number index (from 1) found by the last CountHostIPs, as an integer IP address.

## Plugins and libraries

### CallDLL

`CallDLL(dll_name$, proc_name$, [in_bank%=0], [out_bank%=0])` → integer

Calls the function proc_name in the shared library dll_name, passing the contents of in_bank and out_bank (0 for none); the function can write results into out_bank. Returns the function's integer result. The library stays loaded.

### UpdateWorld

`UpdateWorld [elapsed_time#=1]`

Updates animations, collisions and physics for one frame; elapsed_time scales how far animations advance (default 1).

### RenderWorld

`RenderWorld [tween#=1]`

Renders the 3D world from every active camera, covering any 2D drawn before it. tween (0 to 1) blends each entity between its CaptureWorld position and its current one, for smooth fixed-rate loops; 1 draws the current positions.

### Flip

`Flip [vwait%=1]`

Shows the finished frame on screen and ends the frame; vwait (default 1) waits for the vertical blank.

### WireFrame

`WireFrame enable%`

Draws all 3D geometry as wireframe when enable is 1, solid when 0.

## Gamma and quality

### GraphicsQuality

`GraphicsQuality level%`

**(ext)** Sets the renderer quality preset: level 0 low, 1 medium, 2 high, 3 ultra (QUALITY_LOW to QUALITY_ULTRA). Use a low level for old graphics cards.

### GetGraphicsQuality

`GetGraphicsQuality()` → integer

**(ext)** Returns the current quality level set with GraphicsQuality (0-3).

### PostEffect

`PostEffect effect%, [enable%=1]`

**(ext)** Turns a rendering effect on (enable = 1) or off (enable = 0): EFFECT_BLOOM, EFFECT_SSAO, EFFECT_FXAA, EFFECT_SHADOWS or EFFECT_LIGHT_SCATTER.

### AntiAlias

`AntiAlias enable%`

Turns anti-aliasing (smoothing of jagged edges) on or off.

### SetGamma

`SetGamma src_red%, src_green%, src_blue%, dest_red#, dest_green#, dest_blue#`

Sets the gamma ramp so that the colour levels src_red, src_green, src_blue (0-255) are shown as dest_red, dest_green, dest_blue. Call UpdateGamma to apply it.

### UpdateGamma

`UpdateGamma [calibrate%=0]`

Applies the gamma changes made with SetGamma; calibrate is accepted for compatibility.

### GammaRed

`GammaRed(red%)` → float

Returns the output level the red level red (0-255) is mapped to by the gamma ramp.

### GammaGreen

`GammaGreen(green%)` → float

Returns the output level the green level green (0-255) is mapped to by the gamma ramp.

### GammaBlue

`GammaBlue(blue%)` → float

Returns the output level the blue level blue (0-255) is mapped to by the gamma ramp.

## 2D drawing and text

`Locate x%, y%`

Moves the text cursor used by Print and Write to x, y in pixels.

### Viewport

`CreateMesh([brush%=0], [parent%=0])` → integer

Creates an empty mesh and returns its handle; brush and parent are optional.

### CreateSurface

`CreateSurface(mesh%, [brush%=0])` → integer

Adds a new empty surface to mesh, optionally painted with brush, and returns its handle.

### CountSurfaces

`CountSurfaces(mesh%)` → integer

Returns the number of surfaces in mesh.

### GetSurface

`GetSurface(mesh%, index%)` → integer

Returns the handle of surface number index (starting at 1) of mesh.

### AddVertex

`AddVertex(surface%, x#, y#, z#, [u#=0], [v#=0], [w#=1])` → integer

Adds a vertex at x, y, z with texture coordinates u, v, w to surface and returns its index (starting at 0).

### AddTriangle

`AddTriangle(surface%, v0%, v1%, v2%)` → integer

Adds a triangle joining vertices v0, v1 and v2 to surface and returns its index.

### ClearSurface

`ClearSurface surface%, [clear_vertices%=1], [clear_triangles%=1]`

Removes the vertices and/or triangles from surface, as chosen by clear_vertices and clear_triangles (both default 1).

### CountVertices

`CountVertices(surface%)` → integer

Returns the number of vertices in surface.

### CountTriangles

`CountTriangles(surface%)` → integer

Returns the number of triangles in surface.

### TriangleVertex

`TriangleVertex(surface%, triangle%, corner%)` → integer

Returns the index of the vertex at corner (0, 1 or 2) of triangle in surface.

### VertexCoords

`VertexCoords surface%, index%, x#, y#, z#`

Moves vertex index of surface to x, y, z.

### VertexNormal

`VertexNormal surface%, index%, nx#, ny#, nz#`

Sets the normal of vertex index of surface to nx, ny, nz.

### VertexColor

`VertexColor surface%, index%, red#, green#, blue#, [alpha#=1]`

Sets the colour of vertex index of surface to red, green, blue (0-255) and alpha (0 to 1, default 1). Shown when the entity uses vertex colours (EntityFX 2).

### VertexData

`VertexData surface%, index%, slot%, x#, [y#=0], [z#=0], [w#=0]`

**(ext)** Stores up to four extra values x, y, z, w in data slot (0 to 3) of vertex index of surface, for use by custom shaders.

### VertexDataValue

`VertexDataValue(surface%, index%, slot%, component%)` → float

**(ext)** Returns one component (0 to 3) of data slot (0 to 3) of vertex index of surface, as set with VertexData.

### VertexTexCoords

`VertexTexCoords surface%, index%, u#, v#, [w#=1], [coord_set%=0]`

Sets the texture coordinates u, v, w of vertex index of surface in coordinate set coord_set (0 or 1).

### VertexX

`VertexX(surface%, index%)` → float

Returns the X position of vertex index of surface.

### VertexY

`VertexY(surface%, index%)` → float

Returns the Y position of vertex index of surface.

### VertexZ

`VertexZ(surface%, index%)` → float

Returns the Z position of vertex index of surface.

### VertexNX

`VertexNX(surface%, index%)` → float

Returns the X part of the normal of vertex index of surface.

### VertexNY

`VertexNY(surface%, index%)` → float

Returns the Y part of the normal of vertex index of surface.

### VertexNZ

`VertexNZ(surface%, index%)` → float

Returns the Z part of the normal of vertex index of surface.

### VertexRed

`VertexRed(surface%, index%)` → float

Returns the red component (0-255) of the colour of vertex index of surface.

### VertexGreen

`VertexGreen(surface%, index%)` → float

Returns the green component (0-255) of the colour of vertex index of surface.

### VertexBlue

`VertexBlue(surface%, index%)` → float

Returns the blue component (0-255) of the colour of vertex index of surface.

### VertexAlpha

`VertexAlpha(surface%, index%)` → float

Returns the alpha (0 to 1) of vertex index of surface.

### VertexU

`VertexU(surface%, index%, [coord_set%=0])` → float

Returns the U texture coordinate of vertex index of surface in coordinate set coord_set.

### VertexV

`VertexV(surface%, index%, [coord_set%=0])` → float

Returns the V texture coordinate of vertex index of surface in coordinate set coord_set.

### VertexW

`VertexW(surface%, index%, [coord_set%=0])` → float

Returns the W texture coordinate of vertex index of surface in coordinate set coord_set.

### UpdateNormals

`UpdateNormals mesh%`

Recalculates the normals of every vertex in mesh for smooth lighting.

### FlipMesh

`FlipMesh mesh%`

Reverses the triangles of mesh so it faces the other way.

### ScaleMesh

`ScaleMesh mesh%, x_scale#, y_scale#, z_scale#`

Scales the vertices of mesh by x_scale, y_scale, z_scale, changing the geometry itself.

### PositionMesh

`PositionMesh mesh%, x#, y#, z#`

Moves the vertices of mesh by x, y, z, changing the geometry itself.

### RotateMesh

`RotateMesh mesh%, pitch#, yaw#, roll#`

Rotates the vertices of mesh by pitch, yaw and roll in degrees, changing the geometry itself.

### FitMesh

`FitMesh mesh%, x#, y#, z#, width#, height#, depth#, [uniform%=0]`

Scales and moves the vertices of mesh to fit the box at x, y, z of size width, height, depth; uniform 1 keeps the mesh's proportions.

### AddMesh

`AddMesh source_mesh%, dest_mesh%`

Copies the surfaces of source_mesh into dest_mesh.

### CopyMesh

`CopyMesh(mesh%, [parent%=0])` → integer

Creates a new mesh with a copy of the geometry of mesh and returns its handle; parent is optional.

### MeshCullBox

`MeshCullBox mesh%, x#, y#, z#, width#, height#, depth#`

Accepted for compatibility; meshes are culled by their real bounds.

### FindSurface

`FindSurface(mesh%, brush%)` → integer

Returns the surface of mesh painted with brush, or 0 if there is none.

### MeshesIntersect

`MeshesIntersect(mesh_a%, mesh_b%)` → integer

### MeshWidth

`MeshWidth(mesh%)` → float

Returns the width (size along X) of mesh, in world units.

### MeshHeight

`MeshHeight(mesh%)` → float

Returns the height (size along Y) of mesh, in world units.

### MeshDepth

`MeshDepth(mesh%)` → float

Returns the depth (size along Z) of mesh, in world units.

### CountMeshTriangles

`CountMeshTriangles(mesh%)` → integer

**(ext)** Returns the total number of triangles in all surfaces of mesh.

## Models and animation

### CaptureWorld

`CaptureWorld`

Records the position, rotation and scale of every entity, for RenderWorld tweening.

### AddAnimSeq

`AddAnimSeq(entity%, length%)` → integer

Adds an empty keyframe animation sequence of length frames to entity and returns its number; fill it with SetAnimKey.

### SetAnimKey

`SetAnimKey entity%, frame%, [pos_key%=1], [rot_key%=1], [scale_key%=1]`

Stores entity's current position, rotation and/or scale (chosen by pos_key, rot_key, scale_key) as a key at frame of its last added sequence.

### LoaderMatrix

`LoaderMatrix file_extension$, xx#, xy#, xz#, yx#, yy#, yz#, zx#, zy#, zz#`

Sets the matrix applied to models loaded from files with file_extension; the three rows xx,xy,xz / yx,yy,yz / zx,zy,zz are the new X, Y and Z axes.

### LoadAnimSeq

`LoadAnimSeq(entity%, file$)` → integer

Loads the animations from another model file and adds them to the animated model entity (retargeted to its skeleton); returns the number of the first new sequence, or -1 on failure.

### LoadMesh

`LoadMesh(file$, [parent%=0])` → integer

Loads a glTF (.gltf/.glb), FBX or saved scene file as a single entity and returns its handle, or 0 on failure; parent is optional. Old Blitz formats (.b3d, .x, .3ds) are not supported.

### LoadMeshAsync

`LoadMeshAsync(file$, [parent%=0])` → integer

**(ext)** Starts loading a model file in the background and returns its entity at once; the model appears in it when loaded. parent is optional.

### EntityLoaded

`EntityLoaded(entity%)` → integer

**(ext)** Returns 1 if the model of entity has finished loading (always for other entities), 0 while it is still loading, -1 if loading failed.

### PendingLoads

`PendingLoads()` → integer

**(ext)** Returns the number of background model and texture loads still in progress.

### LoadAnimMesh

`LoadAnimMesh(file$, [parent%=0])` → integer

Loads an animated model (with its bone hierarchy and animations) from file and returns it as an entity, optionally attached to parent. Returns 0 if the file cannot be loaded.

### Animate

`Animate entity%, [mode%=1], [speed#=1], [sequence%=0], [transition#=0]`

Starts animating entity: mode 0 stops, 1 loops, 2 ping-pongs, 3 plays once; speed scales playback, sequence picks the animation sequence and transition is the number of frames to blend from the current pose.

### SetAnimTime

`SetAnimTime entity%, time#, [sequence%=0]`

Jumps entity's animation to time (in frames) in the given sequence.

### Animating

`Animating(entity%)` → integer

Returns 1 if entity is currently animating, otherwise 0.

### AnimTime

`AnimTime(entity%)` → float

Returns the current time (frame) of entity's animation.

### AnimSeq

`AnimSeq(entity%)` → integer

Returns the animation sequence entity is currently playing.

### AnimLength

`AnimLength(entity%)` → integer

Returns the length in frames of entity's current animation sequence.

### ExtractAnimSeq

`ExtractAnimSeq(entity%, first_frame%, last_frame%, [anim_seq%=0])` → integer

Creates a new animation sequence from frames first_frame to last_frame of sequence anim_seq and returns the new sequence's number.

### CountAnimSeqs

`CountAnimSeqs(entity%)` → integer

**(ext)** Returns how many animation sequences entity has (0 if it is not animated).

### AnimLayer

`AnimLayer entity%, layer%, sequence%, [mode%=1], [speed#=1], [weight#=1], [bone$=""]`

**(ext)** Plays sequence on animation layer (1-8) of entity on top of its main animation, blended in by weight (0-1); mode and speed work like Animate. bone limits the layer to that bone and everything below it ("" = the whole model), e.g. the upper body shooting while the legs run; a whole-body layer at weight 0.3 mixes the two animations 70/30.

### AnimLayerWeight

`AnimLayerWeight entity%, layer%, weight#`

**(ext)** Changes how strongly animation layer of entity is blended in, from 0 (not at all) to 1 (fully); change it a little each frame to fade a layer in or out.

### AnimLayerStop

`AnimLayerStop entity%, layer%`

**(ext)** Removes animation layer from entity.

### CreateBlendSpace

`CreateBlendSpace()` → integer

**(ext)** Creates an empty blend space and returns its handle; add sequences to it with BlendSpacePoint and play it with AnimBlend or AddBlendState.

### BlendSpacePoint

`BlendSpacePoint space%, sequence%, x#, [y#=0]`

**(ext)** Places animation sequence at point x (and y) of blend space, e.g. idle at 0, walk at 1 and run at 3 for speed. Points that all share one y form a line; otherwise they form a plane (speed and direction).

### AnimBlend

`AnimBlend entity%, space%, x#, [y#=0], [speed#=1], [transition#=0]`

**(ext)** Plays blend space on entity, mixing its sequences for the point x,y (call it again each frame with new values; the mix changes smoothly). All sequences stay at the same point of their cycle so steps stay in step. speed scales playback; transition crossfades from the previous animation over that many frames.

### AddAnimState

`AddAnimState(entity%, name$, sequence%, [mode%=1], [speed#=1])` → integer

**(ext)** Adds a state called name to entity's animation state machine that plays sequence with mode (1 loop, 2 ping-pong, 3 once) and speed; returns the state's number.

### AddBlendState

`AddBlendState(entity%, name$, space%, param_x$, [param_y$=""], [speed#=1])` → integer

**(ext)** Adds a state called name to entity's animation state machine that plays blend space, its position taken each frame from the parameters param_x (and param_y) set with SetAnimParam; returns the state's number.

### AddAnimTransition

`AddAnimTransition entity%, from$, to$, [condition$=""], [duration#=10]`

**(ext)** Makes entity's state machine switch from state from ("*" or "" for any state) to state to when condition holds, crossfading over duration frames. condition is "" (at once), "end" (the state's one-shot animation has finished) or a comparison of a parameter such as "speed > 0.5" (operators > < >= <= = <>).

### SetAnimParam

`SetAnimParam entity%, name$, value#`

**(ext)** Sets parameter name of entity's animation state machine to value; transitions and blend states read it.

### AnimParam

`AnimParam(entity%, name$)` → float

**(ext)** Returns the value of parameter name of entity's animation state machine (0 if never set).

### StartAnimStates

`StartAnimStates entity%, state$`

**(ext)** Starts entity's animation state machine in state; from then on UpdateWorld takes its transitions by itself.

### AnimStateName

`AnimStateName(entity%)` → string

**(ext)** Returns the name of the state entity's animation state machine is in, or "" if it has none.

### AnimRootMotion

`AnimRootMotion entity%, [bone$=""], [enable%=1], [keep_y%=1]`

**(ext)** Root motion: the movement of the root bone in entity's animation moves the entity instead, so its feet do not slide (for animations made moving forward rather than in place). bone picks the root bone ("" = the model's topmost moving bone); enable 0 turns it off; keep_y 1 leaves up and down movement in the animation.

### CreateTrack

`CreateTrack(entity%, property$)` → integer

**(ext)** Creates a property track that animates property of entity and returns its handle. property is position, rotation, scale, color, alpha, shininess, emissive, lightcolor, lightrange, camerazoom, fogrange, texture (offset of the entity's first texture) or texturerotation; add keys with TrackKey.

### TrackKey

`TrackKey track%, frame#, value1#, [value2#=0], [value3#=0]`

**(ext)** Sets the value of track at frame (1/60 s each): value1 to value3 as the property needs (x,y,z; red,green,blue; near,far; u,v; or one value). Values between keys change in a straight line.

### PlayTrack

`PlayTrack track%, [mode%=1], [speed#=1]`

**(ext)** Plays track from its start: mode 1 loops, 2 goes back and forth, 3 plays once, 0 stops; speed scales it (negative plays backwards). Tracks advance in UpdateWorld.

### SetTrackTime

`SetTrackTime track%, frame#`

**(ext)** Stops track and sets its property to the value at frame.

### TrackTime

`TrackTime(track%)` → float

**(ext)** Returns the current frame of track.

### TrackPlaying

`TrackPlaying(track%)` → integer

**(ext)** Returns 1 while track is playing, 0 when stopped or finished.

### FreeTrack

`FreeTrack track%`

**(ext)** Deletes track; the property keeps its last value.

### LoadSprite

## Terrain

### CreateTerrain

`CreateTerrain(grid_size%, [parent%=0])` → integer

Creates a flat terrain of grid_size by grid_size squares (a power of 2) and returns its handle; parent is optional.

### LoadTerrain

`LoadTerrain(file$, [parent%=0])` → integer

Creates a terrain from a heightmap image file (brightness is height) and returns its handle; parent is optional.

### TerrainSize

`TerrainSize(terrain%)` → integer

Returns the grid size of terrain.

### TerrainHeight

`TerrainHeight(terrain%, grid_x%, grid_z%)` → float

Returns the height of terrain at grid point grid_x, grid_z, from 0 to 1.

### ModifyTerrain

`ModifyTerrain terrain%, grid_x%, grid_z%, height#, [realtime%=0]`

Sets the height of terrain at grid point grid_x, grid_z to height (0 to 1); realtime is accepted for compatibility.

### TerrainY

`TerrainY(terrain%, x#, y#, z#)` → float

Returns the world Y height of terrain at world position x, y, z.

### TerrainX

`TerrainX(terrain%, x#, y#, z#)` → float

Returns the world X of the terrain point under world position x, y, z.

### TerrainZ

`TerrainZ(terrain%, x#, y#, z#)` → float

Returns the world Z of the terrain point under world position x, y, z.

### TerrainDetail

`TerrainDetail terrain%, detail_level%, [vertex_morph%=0]`

Sets terrain level of detail: about detail_level triangles are drawn, with full detail near the camera and fewer, larger squares further away (chosen every render). 0 draws the full grid (the default). vertex_morph is accepted. Collisions and picks always use the full grid.

### TerrainShading

`TerrainShading terrain%, enable%`

Accepted for compatibility; terrain shading is handled by the GPU.

### TerrainLayer

`TerrainLayer terrain%, texture%, [layer%=0]`

**(ext)** Gives terrain a texture for layer 0 (the base, the same as EntityTexture) to 3. Layers 1 to 3 are painted over the base with PaintTerrain or LoadTerrainLayers (grass, rock, sand, snow...); scale them with ScaleTexture.

### PaintTerrain

`PaintTerrain terrain%, layer%, x#, z#, radius#, [strength#=1]`

**(ext)** Paints layer (0-3) of terrain with a soft round brush at world position x, z: radius in world units, strength 0-1 (how much a single stroke adds; negative removes). Painting a layer also uncovers it from the layers above it; painting layer 0 brings the base back.

### ErodeTerrain

`ErodeTerrain terrain%, [droplets%=50000], [seed%=0]`

**(ext)** Erodes terrain with simulated rain: droplets raindrops each run downhill, taking soil from the slopes and leaving it where they slow down, which carves gullies and ridges into mountains and fills valleys. More droplets erode more (try 50000 to 300000 for a 256 terrain); the same seed gives the same result. Set the terrain's ScaleEntity first: steepness depends on its proportions.

### ThermalErodeTerrain

`ThermalErodeTerrain terrain%, [iterations%=30], [max_angle#=40]`

**(ext)** Lets slopes of terrain steeper than max_angle degrees crumble down until they are no steeper, repeated iterations times: softens sharp peaks and builds scree at the foot of cliffs. Set the terrain's ScaleEntity first.

### ModifyTerrainLayer

`ModifyTerrainLayer terrain%, grid_x%, grid_z%, layer%, weight#`

**(ext)** Sets how much painted layer (1-3) covers terrain at grid point grid_x, grid_z, from 0 to 1, without changing the other layers (like ModifyTerrain for heights; layers above still cover it). Useful for painting by height or slope in a loop.

### TerrainLayerWeight

`TerrainLayerWeight(terrain%, layer%, x#, z#)` → float

**(ext)** Returns how much of layer (0-3) shows on terrain at world position x, z, from 0 to 1 (for footstep sounds, placing trees on grass, slowing down in sand).

### LoadTerrainLayers

`LoadTerrainLayers terrain%, file$`

**(ext)** Paints terrain's layers 1, 2 and 3 from the red, green and blue of an image file (a splat map, as painted in another program), stretched over the whole terrain; the top of the image is the far (+Z) edge.

## 3D physics

### EntityPhysics

`EntityPhysics entity%, [body_type%=1], [shape%=0], [mass#=1]`

**(ext)** Makes entity a rigid body: body_type 1 dynamic, 2 static, 3 kinematic; shape 0 automatic, 1 box, 2 sphere, 3 capsule, 4 cylinder, 5 mesh, 6 convex hull; mass in kilograms.

### PhysicsGravity

`PhysicsGravity x#, y#, z#`

**(ext)** Sets the world's gravity vector x, y, z, in units per second squared.

### EntityMass

`EntityMass entity%, mass#`

**(ext)** Sets the mass of entity's physics body.

### EntityFriction

`EntityFriction entity%, friction#`

**(ext)** Sets the friction of entity's physics body (0 is slippery).

### EntityBounce

`EntityBounce entity%, bounce#`

**(ext)** Sets how bouncy entity's physics body is, from 0 (no bounce) to 1.

### EntityDamping

`EntityDamping entity%, linear#, angular#`

**(ext)** Sets the linear and angular damping of entity's physics body, which slows its movement and spin.

### EntityGravityScale

`EntityGravityScale entity%, scale#`

**(ext)** Scales how much gravity affects entity's physics body (0 none, 1 normal).

### LockRotation

`LockRotation entity%, x%, y%, z%`

**(ext)** Stops entity's physics body rotating about each axis whose flag x, y, z is 1.

### ApplyForce

`ApplyForce entity%, x#, y#, z#`

**(ext)** Applies a continuous force x, y, z to entity's physics body.

### ApplyImpulse

`ApplyImpulse entity%, x#, y#, z#`

**(ext)** Gives entity's physics body an instant push x, y, z.

### ApplyImpulseAt

`ApplyImpulseAt entity%, x#, y#, z#, point_x#, point_y#, point_z#`

**(ext)** Gives entity's physics body an instant push x, y, z at the world point point_x, point_y, point_z, which can also make it spin.

### ApplyTorque

`ApplyTorque entity%, x#, y#, z#`

**(ext)** Applies a continuous turning force x, y, z to entity's physics body.

### ApplyTorqueImpulse

`ApplyTorqueImpulse entity%, x#, y#, z#`

**(ext)** Gives entity's physics body an instant spin x, y, z.

### SetVelocity

`SetVelocity entity%, x#, y#, z#`

**(ext)** Sets the velocity of entity's physics body, in units per second.

### SetAngularVelocity

`SetAngularVelocity entity%, x#, y#, z#`

### VelocityX

### VelocityY

**(ext)** Returns the Y velocity of entity's physics body, in units per second.

### VelocityZ

**(ext)** Returns the Z velocity of entity's physics body, in units per second.

### AngularVelocityX

## AI and pathfinding

### CreateNavMesh

`CreateNavMesh(entity%, [max_slope#=45])` → integer

**(ext)** Makes a navigation mesh (the ground characters can walk on) from entity's mesh, in world space, keeping triangles that slope at most max_slope degrees; returns its handle. Use a mesh made for walking, or a level's floor. Also called CreateNavigationMesh.

### GenerateNavMesh

`GenerateNavMesh(x#, z#, width#, depth#, [cell_size#=1], [max_slope#=45], [step_height#=0.5], [top#=1000])` → integer

**(ext)** Makes a navigation mesh by looking down on the pickable entities (EntityPickMode) over the area from x, z to x + width, z + depth every cell_size units: ground that slopes at most max_slope degrees is kept, and neighbouring points join when their heights differ by at most step_height, so walls and boxes become holes. top is the height to look down from. Returns its handle.

### CreateBehavior

`CreateBehavior([name$=""])` → integer

**(ext)** Creates an empty behaviour tree for decision making and returns its handle; add nodes with BehaviorSelector, BehaviorSequence, BehaviorInvert, BehaviorIf and BehaviorDo (the first node without a parent is the root).

### LoadBehavior

`LoadBehavior(file$)` → integer

**(ext)** Loads a behaviour tree from a text file and returns its handle. Each line is a node, children indented under their parent: selector, sequence, invert, if <condition>, do <action>; a semicolon starts a comment.

### BehaviorFromText

`BehaviorFromText(text$)` → integer

**(ext)** Makes a behaviour tree from text written like a LoadBehavior file (lines separated by Chr(10)) and returns its handle.

### BehaviorSelector

`BehaviorSelector(behavior%, [parent%=0])` → integer

**(ext)** Adds a selector node under parent (0 = top level) to behavior and returns its node number: it tries its children in order until one succeeds or is running, so the first that applies wins.

### BehaviorSequence

`BehaviorSequence(behavior%, [parent%=0])` → integer

**(ext)** Adds a sequence node under parent to behavior and returns its node number: it runs its children in order while they succeed.

### BehaviorInvert

`BehaviorInvert(behavior%, [parent%=0])` → integer

**(ext)** Adds an invert node under parent to behavior and returns its node number: its one child's success counts as failure and failure as success.

### BehaviorIf

`BehaviorIf(behavior%, condition$, [parent%=0])` → integer

**(ext)** Adds a condition node under parent to behavior and returns its node number. The condition compares parameters set with SetBehaviorParam and numbers, like "dist < 10" or "health >= max" (< <= > >= = <>), or is just a parameter name (true when not 0).

### BehaviorDo

`BehaviorDo(behavior%, action$, [parent%=0])` → integer

**(ext)** Adds an action node under parent to behavior and returns its node number. The action is a name the program acts on when BehaviorAction returns it.

### FreeBehavior

`FreeBehavior behavior%`

**(ext)** Frees behavior and stops every character using it.

### SetBehavior

`SetBehavior entity%, behavior%`

**(ext)** Makes entity (or any number that names a character) use behavior; 0 removes it. Each character keeps its own parameters and progress.

### SetBehaviorParam

`SetBehaviorParam entity%, name$, value#`

**(ext)** Sets parameter name of entity's behaviour to value, for its conditions to compare (names are not case-sensitive; parameters not set are 0).

### BehaviorParam

`BehaviorParam(entity%, name$)` → float

**(ext)** Returns parameter name of entity's behaviour.

### BehaviorAction

`BehaviorAction(entity%)` → string

**(ext)** Evaluates entity's behaviour tree and returns the action to do now, or "" if none. Conditions are checked every time, so a more important branch takes over as soon as it applies. Do the action every frame until it is finished, then call BehaviorResult.

### BehaviorResult

`BehaviorResult entity%, [success%=1]`

**(ext)** Tells entity's behaviour that the current action finished: success 1 (the default) if it worked, 0 if it failed, so sequences go on to their next step and selectors try their next choice.

## Post-processing

### CreatePostProcess

`CreatePostProcess(source$, [language$="glsl"])` → integer

**(ext)** Creates a post-processing effect from source (GLSL with vec4 nb_post(vec2 uv), or WGSL) and returns it. Add it to a camera with AddPostProcess.

`LoadPostProcess(file$)` → integer

**(ext)** Loads a post-processing effect from a file or "builtin:<name>" (bloom, exposure, tonemap, vignette, chromatic, grain, colorgrade, gamma, contrast, saturation, brightness, fxaa, outline, pixelate, crt, distortion, heathaze, blur, gaussian, radialblur, sharpen, dof, motionblur, ssr, ssao, fog, underwater, rain, snow, invert) and returns it, or 0 on failure.

**(ext)** Adds effect to the chain of camera (0 = every camera).

`RemovePostProcess effect%, [camera%=0]`

**(ext)** Removes effect from the chain of camera (0 = from every chain); the effect still exists.

### FreePostProcess

`FreePostProcess effect%`

**(ext)** Removes effect from every chain and frees it.

### SetPostProcess

`SetPostProcess camera%, effect%`

**(ext)** Makes effect the only effect of camera; effect 0 clears camera's chain.

### SetPostProcessParameter

`SetPostProcessParameter effect%, name$, value$`

**(ext)** Sets the parameter called name of effect from text (numbers separated by commas, or a texture handle).

### SetPostProcessEnabled

`SetPostProcessEnabled effect%, enable%`

**(ext)** Turns effect on (enable 1) or off (0) without removing it from its chains.

### SetPostProcessOrder

**(ext)** Sets where effect runs in its chain: lower orders run first (effects start in the order they were made).

### PostProcessResolution

### PostProcessCamera

`PostProcessCamera effect%, camera%`

**(ext)** Makes effect run only for camera.

### PostProcessPriority

`PostProcessPriority effect%, priority%`

**(ext)** A negative priority runs effect on the HDR image before tone mapping; 0 or more runs it on the final image.

### PostProcessShader

`PostProcessShader(effect%)` → integer

**(ext)** Returns the shader of effect, for the ShaderSet* and Shader debugging commands.

**(ext)** Draws falling snow over camera's view with amount 0-1 (0 turns it off) and speed.

**(ext)** Adds height fog to camera from the depth buffer: density (0 turns it off), colour red, green, blue, and how fast it thins with height.

## Loading and saving scenes

### SaveScene

`SaveScene(file$)` → integer

**(ext)** Saves every top-level entity as a Fyrox scene file (.rgs) that LoadMesh can load back as one entity; cameras, collision, pick and physics settings and sounds are not saved. Returns 1 on success.

### SaveEntity

`SaveEntity(entity%, file$)` → integer

**(ext)** Saves entity and its children as a Fyrox scene file (.rgs) named file, to be loaded back with LoadMesh. Returns 1 on success.

### ReloadAssets

`ReloadAssets()` → integer

**(ext)** Reads every loaded texture, image, sound and model again from its file, keeping each handle's settings (scale, frames, handle, volume, ...) and the entities using them; returns how many were reloaded. Useful after changing art while the game runs.

### WatchAssets

`WatchAssets [enable%=1]`

**(ext)** With enable 1, checks the files of loaded textures, images, sounds and models about once a second and reloads the ones that changed on disk, so art edited in another program shows up while the game runs; 0 stops watching.

### AssetsReloaded

`AssetsReloaded()` → integer

**(ext)** Returns how many assets were reloaded (by ReloadAssets or WatchAssets) since the last call.

### ModelName

`ModelName(entity%)` → string

**(ext)** Returns the file entity's model was loaded from, or "" if it is not a loaded model.

### LoadPrefab

`LoadPrefab(file$)` → integer

**(ext)** Loads a model or saved scene file (from SaveScene or SaveEntity, the Fyrox editor, glTF or FBX) once as a prefab and returns its handle, or 0 if it cannot be loaded. Place it with InstancePrefab.

### CreatePrefab

`CreatePrefab(entity%)` → integer

**(ext)** Makes entity (built in the program, with its children) a prefab and returns its handle. The entity is hidden and kept as the original that InstancePrefab copies.

### EntityBatch

`EntityBatch entity%, [mode%=1]`

**(ext)** Draws the children of mesh entity (one made with CreateMesh) merged into a few batches, one per material, instead of one by one: much faster for forests, rocks and other scenery made of many copies. Mode 1 bakes them where they are now (call again after adding or moving children), 2 merges them every frame so they can move, 0 turns batching off.

### InstancePrefab

`InstancePrefab(prefab%, [parent%=0])` → integer

**(ext)** Places a new copy of prefab and returns the new entity (parent optional). Copies of a file prefab share its meshes, materials and textures, and ReloadAssets updates them all.

### PrefabName

`PrefabName(prefab%)` → string

**(ext)** Returns the file prefab was loaded from, or the name of its original entity.

### EntityPrefab

`EntityPrefab(entity%)` → integer

**(ext)** Returns the prefab entity was placed from with InstancePrefab, or 0.

### FreePrefab

`FreePrefab prefab%`

**(ext)** Frees prefab (and the original entity of a CreatePrefab prefab); copies already placed stay.

### CreateScene

`CreateScene()` → integer

**(ext)** Creates a new empty scene and returns its handle (scene 1 is the one Graphics3D makes). Each scene has its own entities, lights, ambient light, physics and sounds; its cameras draw with a see-through background over the scenes made before it. Use SetScene to build in it.

### SetScene

`SetScene scene%`

**(ext)** Makes scene the current scene: new entities go into it and commands work on its entities (using an entity of another scene is an error, so read what you need before switching).

### CurrentScene

`CurrentScene()` → integer

**(ext)** Returns the current scene.

### ShowScene

`ShowScene scene%`

**(ext)** Shows scene again after HideScene: it is drawn and updated.

### HideScene

`HideScene scene%`

**(ext)** Hides scene: it is not drawn, UpdateWorld does not move it and its physics stops, but everything in it is kept (a paused level, an interior, a menu).

### SceneVisible

`SceneVisible(scene%)` → integer

**(ext)** Returns 1 if scene is shown, 0 if hidden.

### FreeScene

`FreeScene scene%`

**(ext)** Frees scene and every entity in it (scene 1 cannot be freed). If it was current, scene 1 becomes current.

### EntityScene

`EntityScene(entity%)` → integer

**(ext)** Returns the scene entity is in.

### GuiShowPopup

`GuiShowPopup popup%, show%`

**(ext)** Opens a popup at the mouse position (show = 1) or closes it (show = 0).

### GuiMessageBox

`GuiMessageBox(title$, text$, [buttons%=0])` → integer

**(ext)** Shows a message box with a title and text in the middle of the screen at once and blocks clicks on the rest of the GUI until it is answered. buttons: 0 OK, 1 Yes/No, 2 Yes/No/Cancel. When the user answers, GuiChanged becomes non-zero and GuiValue is 1 for OK/Yes, 2 for No, 3 for Cancel. Returns the message box's handle.

### GuiFileBrowser

`GuiFileBrowser(path$, [parent%=0])` → integer

**(ext)** Creates a folder tree that starts at path ("" = the current folder), 300 by 250 pixels; parent is the widget to put it in (0 = the screen). When the user picks a file or folder, GuiChanged becomes non-zero and GuiText returns its path. Returns the browser's handle.

### GuiFileDialog

`GuiFileDialog(title$, path$, [save%=0])` → integer

**(ext)** Opens a file dialog window in the middle of the screen at once, with a title and a starting path (a folder, or a file whose name is filled in). save = 1 makes it a Save dialog. When the user clicks Open/Save, GuiChanged becomes non-zero, GuiValue is 1 and GuiText is the chosen path; when the user clicks Cancel, GuiChanged becomes non-zero and GuiValue is 0. Returns the dialog's handle.

### GuiDock

`GuiDock([parent%=0])` → integer

**(ext)** Creates a docking area, 400 by 300 pixels (resize it with SetGuiSize), where GuiWindows can be docked side by side or as tabs and dragged in and out by the user; parent is the widget to put it in (0 = the screen). Returns the dock's handle.

### GuiDockWindow

`GuiDockWindow dock%, window%, [place%=0]`

**(ext)** Puts a GuiWindow into a dock. place: 0 leaves it floating so the user can drag it onto the dock, 1 docks it on the left, 2 right, 3 top, 4 bottom, 5 as a tab in the middle.

### GuiModal

`GuiModal window%`

**(ext)** Opens a GuiWindow in the middle of the screen as a modal window: the rest of the GUI ignores clicks until the window is closed.

### GuiCenter

`GuiCenter widget%`

**(ext)** Moves a widget to the middle of the widget it is in (the screen for widgets with parent 0).

### GuiNumber

`GuiNumber(value#, [min#=-1000000], [max#=1000000], [step#=1], [parent%=0])` → integer

**(ext)** Creates a number box with up/down arrows (you can also type in it or drag the arrows) showing value, kept between min and max and changed by step per click; returns the widget handle. Read it with GuiValue, set it with SetGuiValue, and GuiChanged tells you when the user edits it.

### GuiVector3

`GuiVector3(x#, y#, z#, [parent%=0])` → integer

**(ext)** Creates an editor with three number boxes for an X, Y, Z vector, starting at x, y, z; returns the widget handle. Read the parts with GuiVectorValue, set them with SetGuiVector; GuiChanged tells you when the user edits it.

### GuiColorPicker

`GuiColorPicker([red%=255], [green%=255], [blue%=255], [parent%=0])` → integer

**(ext)** Creates a full colour picker (colour square, hue and alpha bars, RGB/HSV boxes) starting at the colour red, green, blue (0-255, default white); returns the widget handle. Read the colour with GuiVectorValue (0 red, 1 green, 2 blue, 3 alpha), set it with SetGuiVector; GuiChanged tells you when the user picks a colour.

### GuiColorField

`GuiColorField(red%, green%, blue%, [parent%=0])` → integer

**(ext)** Creates a small colour swatch showing red, green, blue (0-255) that opens a colour picker when clicked; returns the widget handle. The new colour arrives when the picker closes: read it with GuiVectorValue (0 red, 1 green, 2 blue, 3 alpha), set it with SetGuiVector; GuiChanged tells you when it changes.

### GuiVectorValue

`GuiVectorValue(widget%, component%)` → float

**(ext)** Returns one part of a vector editor or colour widget as a float: component 0, 1, 2 are x, y, z of a GuiVector3, or 0-3 are red, green, blue, alpha (0-255) of a GuiColorPicker or GuiColorField.

### SetGuiVector

`SetGuiVector widget%, x#, y#, z#, [w#=255]`

**(ext)** Sets a GuiVector3 to x, y, z, or a GuiColorPicker or GuiColorField to the colour x=red, y=green, z=blue, w=alpha (0-255, 255 if left out). Does not count as a change for GuiChanged.

### GuiCurve

`GuiCurve([parent%=0])` → integer

**(ext)** Creates a curve editor showing a curve that starts as a straight line from (0,0) to (1,1); the user can drag, add and remove keys (right-click for the menu). Returns the widget handle; GuiChanged tells you when the user edits the curve.

### GuiCurveKey

`GuiCurveKey curve%, x#, y#`

**(ext)** Adds a key (point) at position x with value y to a GuiCurve; the curve is a straight line between keys.

### GuiClearCurve

`GuiClearCurve curve%`

**(ext)** Removes every key from a GuiCurve, leaving it empty (an empty curve has the value 0 everywhere).

### GuiCurveValue

`GuiCurveValue(curve%, x#)` → float

**(ext)** Returns the value of a GuiCurve at position x, following the curve as currently edited by the user; before the first key it is the first key's value and after the last key the last key's value.
